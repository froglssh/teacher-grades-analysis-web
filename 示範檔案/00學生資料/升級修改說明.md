# 班級學生資料管理系統 v3.0 升級說明

目標檔案：`班級學生資料管理系統.html`（檔名不變，工作站首頁連結照常可用）
舊版備份：`OLD/班級學生資料管理系統_備份_v2_20261121.html`（使用說明也一併備份）

## 老師的決定（2026-11-21）

- 導師一年只帶一個班，換班後清空 → **單一班級**，資料夾只放一個檔，不分班級。
- **身分證字號用不到** → 不儲存、不匯入、不寫入資料夾或 JSON。
- **要與「班級經營整合工作站」共用名冊連動**（幹部、座位、打掃、成績、德性都用同一班學生）。
- 要做 **全班總覽模式**。
- 依序進行：第 1 階段儲存 → 第 2 階段介面 → 第 3 階段操作（含總覽、工作站連動）→ 第 4 階段說明與收尾。

## 第 1 階段：儲存架構（✅ 已完成，2026-11-21）

### 儲存位置
| 層 | 內容 |
|---|---|
| IndexedDB `lssh-student-data` | `kv`：`state`、`folderHandle`、`folderKnown`、`legacyBackupsMigrated`；`snapshots`：自動還原點 |
| localStorage `lssh_class_student_mgr_v1` | 鏡像／後援（沿用舊鍵名，舊版程式仍讀得到）。資料太大存不下時自動停用，不影響 IndexedDB |
| 資料夾正本（Chrome／Edge） | `班級學生資料.json`；`班級學生資料_歷史/` 每天一份（留 14 份）；兩台電腦衝突時另存 `班級學生資料_衝突_<裝置>_<時間>.json` |
| AI 金鑰 | 仍只存 localStorage `lssh_ai_cfg`，**絕不**寫入 IndexedDB 狀態、資料夾或 JSON |

### 舊資料自動搬移
- 第一次開啟 v3.0：讀舊版 localStorage → 搬進 IndexedDB → 讀回比對一致才採用。
- 舊版「班級備份庫」的每一份都轉成「舊版班級備份庫」還原點（不會被自動刪除，可還原、下載、刪除）。
- 主資料空白時，比照舊版判斷改用備份庫中「目前」或最新的一份。
- 搬移時一併去除身分證字號；舊版 localStorage 備份庫原樣保留，可在「資料存放與還原」按「清除舊版瀏覽器備份」。

### 自動還原點
- 每天第一次儲存時 1 份（留 7 天）。
- 重要動作前 1 份（留 10 份）：換新班級（清空）、匯入任何檔案、匯入整班 JSON、刪除欄位／列／自訂項目、還原、從資料夾載入、被另一分頁覆蓋前。

### 介面變動
- 側欄「📚 班級備份庫」→「📁 資料存放與還原」（下方小字顯示目前存放狀態）。
- 頂端加兩個狀態標籤：💾 儲存狀態、📁 資料夾狀態，點一下打開「資料存放與還原」。
- 「💾 儲存到班級資料庫」→「💾 立即儲存」（也可按 Ctrl／⌘＋S）。
- 側欄「💾 備份班級」移到「資料存放與還原 → 下載整班備份 JSON」；「🗑 清空」改名「🗑 換新班級」，改用正式對話框，清空前留還原點。
- 頂端黃色提示列：資料夾需要重新授權、另一台電腦已更新、資料夾讀取失敗。

### 同步行為
- 0.3 秒合併寫入 IndexedDB；2 秒後寫入資料夾；切換或關閉分頁時立即寫出。
- 回到頁面與每 60 秒檢查資料夾是否被另一台電腦更新；本頁沒有修改 → 提示列「載入最新資料」；本頁也有修改 → 三選一（載入資料夾／以本頁覆蓋／本頁另存衝突檔）。
- 同一台電腦開兩個分頁：一邊儲存，另一邊（沒有未存修改時）自動載入；由已連結資料夾的分頁寫出，不會誤判成「另一台電腦」。

### 身分證字號
- 預設欄位移除；匯入基本資料時該欄自動「不匯入」，即使手動選「以此欄標題新增欄位」也會略過。
- 「＋ 欄位」不能新增名稱含「身分證／身份證」的欄位。
- 寫入 IndexedDB、localStorage、資料夾、JSON、還原點前一律再去除一次。

### 測試紀錄（本機 http 伺服器 8799 埠＋內建瀏覽器，獨立網址來源，不影響工作站 8766 的資料）
- 模擬 v2 舊資料（含身分證字號、備份庫 2 份）→ 搬移成功，IndexedDB、鏡像、還原點皆無身分證字號，備份庫轉成 2 個還原點。
- 換新班級 → 留還原點；匯入 `00_成績冊_虛擬姓名.xls`（32 人）與 `01_全班基本資料_虛擬示範.xlsx`，身分證欄強制改「新增欄位」仍被略過。
- 資料夾（以瀏覽器私有檔案系統模擬）：首次連結建立檔案、修改 2 秒後寫入、建立每日歷史；另一台電腦更新 → 提示列 → 載入；雙方都改 → 衝突對話框 → 另存衝突檔並暫停同步。
- 還原點還原、兩個分頁互相同步、重新開啟後自動連回資料夾、資料夾與本機不同時詢問使用哪一份。
- 測試中發現並修正：一個分頁資料夾暫停時，另一個已連結分頁不會把修改寫入資料夾。
- 未實測：真正的「選擇資料夾」視窗與 Google 雲端硬碟同步（需老師在 Chrome／Edge 實際操作一次）。

**整合版行為**
- 學生、姓名、座號、班級名稱來自共用名冊；學生以共用學生 ID 為本工具 ID，改名、換座號資料不會掉。

- 轉出學生：沒資料就不顯示，有資料則保留；不在名冊但有資料的學生保留，頂端提示老師確認。

- 資料存在工作站資料庫，由工作站首頁「資料保存」一併寫入資料夾；AI 金鑰仍只存本機。
