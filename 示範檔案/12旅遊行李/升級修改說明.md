## 老師的決定

- 兩段式勾選要做：先「準備」選要帶的，再「打包」裝箱打勾。
- 旅程清單庫取代舊的「存檔槽」，可同時管理多份旅程。
- 單人使用，不做多人共用清單。
- 「班級經營整合工作站」只維持連結，這次不整合。
- 不打包 APK（資料夾裡既有的 `旅遊行李app-release.apk` 是舊版，這次沒有更新）。

## 一、舊版（v2）問題與改善

| 舊版問題 | v3.0 |
|---|---|
| `todayMid().toISOString().slice(0,10)` 在 UTC+8 會得到前一天：倒數多一天、「今天出發」不出現、天氣範圍偏移 | 全部改用本地日期（`getFullYear/getMonth/getDate`）；日期差用 UTC 午夜整日數計算，不受時區與夏令時間影響 |
| 自訂項目名稱／備註直接進 innerHTML，可被當成 HTML 執行 | 所有輸出一律 `esc()` 跳脫 |
| 航空查無資料時，使用者輸入被插進 `onclick` 字串 | 全檔不再使用 inline 事件；改用事件委派（`data-action`）；Google 搜尋改為一般連結 |
| 只剩一段行程時，按刪除不經確認就清空 | 立即執行＋「復原」按鈕 |
| 分類收合狀態只存在記憶體，重新整理就忘 | 存進每份旅程（`collapsed`） |
| 「刪改」只能移除項目 | 「編輯」可改名、改備註、標重點、移到別分類、移除；內建項目改名存成覆寫，勾選不會遺失 |
| 項目用顯示文字當 key，改名就失去勾選 | 項目改用穩定 id（內建＝分類＋原始名稱雜湊；自訂＝uid） |
| 天氣「去年同期」遇 2/29 會出錯 | 2/29 改用 2/28 |
| 查過的天氣永遠顯示，不知道過期 | 超過 6 小時、不是今天查的、或段落日期改了，顯示「資料可能過期・重新查詢」 |
| 只有一份目前清單，勾選混在一起 | 兩段式：`planned`（要帶）與 `packed`（已裝箱）分開 |
| 存檔槽是名稱字典，無法複製、封存 | 旅程清單庫：切換、複製（可清空勾選）、改名、封存、刪除 |
| 破壞性動作都用 `confirm()`／`alert()` | 自製對話框；取消全部勾選、刪項目、刪行程、封存都「立即執行＋復原」，只有「清除全部資料」與「刪除整份旅程」保留確認 |
| 所有東西擠在一頁、頂部很高 | 四個分頁；手機底部分頁列（含 safe-area）；往下捲標頭縮成一行 |
| 項目是 `div` 點擊，無法用鍵盤 | 真正的 checkbox／button，有 `aria-label`、可見的 focus 樣式 |
| 沒有深色、大字 | 顏色全用 `:root` 變數，自動／淺色／深色；大字模式 |
| 只存 localStorage 兩個鍵；換電腦、清瀏覽器就沒了 | IndexedDB＋localStorage 鏡像＋資料夾正本＋自動還原點 |

### 新功能

- **第一次使用精靈**：沒有旅程時跳出（類型 → 目的地與日期，可略過 → 情境標籤 → 產生清單）；旅程清單「＋新旅程」可隨時再走一次；若已有範本，最後一步可選「套用我的範本」。
- **情境標籤**（👴長輩、👶幼兒、🚗自駕、✈️搭機、🏖️海邊／水上、💼正式、🏝️外島、🏃運動、📷攝影）：對應表寫在資料裡（分類或項目的 `tags`，需要其中任一標籤才顯示；沒有 `tags` 的一律顯示）。國外與競賽預設勾 ✈️。
- **自動數量**：內褲、襪子（天數＋1）、上衣（天數）、長褲／短褲（天數÷2 進位）顯示「×N」，天數取全部段落合計；沒填日期就不顯示。
- **天氣建議一鍵加入**：穿搭標籤「＋加入清單」→ 衣物分類的自訂項目並設為要帶；已在清單顯示 ✓。
- **我的常用設定（範本）**：把目前旅程的移除項目、自訂項目、覆寫存成範本（存在 IndexedDB 與資料夾檔案），新旅程精靈或設定頁可套用。
- **出發前提醒**：最近出發日 ≤1 天（含旅程中）時，「出發前 24 小時最終確認」置頂並加紅框。
- **輸出**：列印選「要帶清單（附空白方格）／未裝箱／全部項目」；「複製成 LINE 文字」（☐／☑），剪貼簿失敗時退回選取文字框。
- **完成感**：分類全部裝箱後自動收合並顯示 ✅；全部裝箱後出現完成畫面。

### 兩個設計取捨（請審核時留意）

1. 打包階段只列出「要帶」的項目，所以「出發前 24 小時最終確認」若沒設為要帶，在打包階段不會出現；出發前提醒橫幅在這種情況下會多一顆「把最終確認全部設為要帶」。
2. 標籤是「需要其中任一標籤才顯示」。「報警 110／消防 119／海巡 118」原本掛在 🏝️，審核後改為國內旅程一律顯示（緊急電話不該被藏起來）。

## 二、儲存架構（比照 06 校慶攤位 v3.0）

| 層 | 內容 |
|---|---|
| IndexedDB `lssh-packing-list`（版本 1） | `kv`：`state`、`folderHandle`、`folderKnown`、`template`、`device`；`snapshots`：還原點 |
| localStorage `lssh.packing.v3` | 鏡像／後援；`lssh.packing.ui` 存分頁、大字、主題 |
| 資料夾正本（Chrome／Edge） | `行李打包清單資料.json`；`行李打包清單資料_歷史/` 每天一份（留 14 份）；兩台電腦衝突時可另存 `行李打包清單資料_衝突_<裝置>_<時間>.json` |

- 0.3 秒合併寫入 IndexedDB；2 秒後寫入資料夾；切換或關閉分頁（`visibilitychange`／`pagehide`）立即寫出。
- 回到頁面與每 60 秒檢查資料夾是否被另一台電腦更新（比對 `savedAt`／`savedBy`／`lastModified`）：本頁沒修改 → 提示列「載入」；有修改 → 衝突對話框（載入資料夾版本／以這台覆蓋／另存衝突檔並暫停同步）。
- 重新整理後用存在 IndexedDB 的資料夾 handle 自動連回；權限不是 `granted` 時顯示「重新授權」。
- BroadcastChannel：另一分頁儲存後，本頁沒修改就自動更新，有修改則詢問。
- `navigator.storage.persist()`，設定頁顯示是否已啟用持久儲存。
- 自動還原點：每天 1 份（留 7 天）；匯入、還原、清除、載入資料夾、刪除旅程前各 1 份（留 10 份）；設定頁可列出、還原、下載。
- 不支援 `showDirectoryPicker`（手機 Safari、Android WebView、Firefox）時，資料夾區塊顯示「此裝置不支援資料夾儲存，請用匯出／匯入檔案備份」，其他功能照常。
- 匯出格式：`{app:"lssh-packing-list",version:3,exportedAt,data:{trips,currentId,template}}`；匯入接受 v3 匯出、v2 匯出（`packing-pro`）與 v2 原始 state。載入／匯入時所有欄位都會驗證，不合法的修正為預設值。
- 舊資料搬移：第一次開啟若 IndexedDB 與鏡像都沒有資料，讀 `packingProV2`（→「目前旅程」）與 `packingProSlots`（每個槽 → 一份旅程），v2 勾選視為「要帶」，並依勾選過的項目推測情境標籤；寫入 IndexedDB 後讀回比對一致才採用；舊鍵原樣保留；跳一次說明。

### 旅程資料結構

```
trips[] = { id, name, mode, tags[], phase, createdAt, updatedAt, archived,
            segments[{id,dest,start,end,memo,memoOpen,weather}],
            items{ id:{planned,packed} }, custom{ 分類id:[{id,label,note,important}] },
            excluded{ id:true }, overrides{ id:{label,note,important,sec} }, collapsed{ 分類id:true } }
state = { trips, currentId, template }
```

## 三、測試紀錄（本機 http 伺服器 8798 埠＋內建瀏覽器，視窗 800×600 與 375×812）

已實測：
- **v2 舊資料搬移**：模擬 `packingProV2`（含 XSS 字串的自訂項目、移除項目、2 段行程、今天出發）＋ 2 個 `packingProSlots` → 轉入 3 份旅程、10 個要帶項目、說明對話框、舊鍵保留、IndexedDB 與鏡像都有資料；XSS 字串以文字顯示，未執行。
- **精靈**：三步驟、略過日期、標籤預設（國外 ✈️）、套用範本、建立後切到清單頁；清除全部後再跳出，按「略過」會建立預設旅程。
- **標籤篩選**：無標籤時 13 個對應項目與 elderly／family／photo 分類都不顯示；逐一加標籤後顯示正確；國內加 ✈️ 或 🏝️ 才出現國內線機票項目。
- **兩段式勾選**：準備階段「已選 N 項」、打包階段「已裝箱 x / N」、打包只列要帶項目、「未完成」篩選在兩階段不同、重點全選、全選此分類、搜尋、重點篩選；分類全部裝箱 → 約 0.7 秒後自動收合並顯示 ✅；全部完成 → 完成畫面。
- **自動數量**：5 天旅程 → 內褲 ×6、上衣 ×5、長褲 ×3、襪子 ×6。
- **編輯**：改名、改備註、標重點、移到別分類後勾選保留；自訂項目的 HTML 以文字顯示；刪除→復原。
- **天氣**（以 stub 取代網路）：失敗畫面（重試＋Google 連結）、成功畫面、一鍵加入並顯示 ✓、超過 6 小時／日期改變／段落日期改變三種過期提示、2028-02-29 去年同期 → 2027-02-28。
- **本地日期**：把 `Date` 換成本地 00:30（UTC+8）驗證 `todayISO()` 為當天（`toISOString` 會是前一天），今天出發顯示「🎉 今天出發」，明天出發觸發出發前提醒。
- **旅程庫**：複製（保留／清空勾選）、封存＋復原、取消封存、改名、刪除（確認對話框＋復原）、刪除前還原點。
- **匯出→清除全部→匯入**：結果與原資料一致；匯入 v2 匯出檔與 v2 原始 state；錯誤檔案顯示說明。
- **還原點**：列出、還原、事件還原點上限 10 份。
- **資料夾**（以 OPFS 模擬 handle）：建立資料檔、修改 2 秒後寫入、每日歷史、另一台電腦更新 → 提示列 → 載入、雙方都改 → 衝突對話框 → 另存衝突檔並暫停 → 立即寫入恢復、重新整理後自動連回。
- **BroadcastChannel**：另一分頁儲存後本頁自動更新；本頁有修改時出現提示列。
- **列印內容**：三種選項各自產生正確的表格列數與方格數（要帶 43／未裝箱 38／全部 161）；列印用 CSS 規則存在。
- **LINE 文字**：內容與 ☐／☑；`clipboard` 失敗退回 `execCommand`；再失敗退回選取文字框。
- **深色／大字／主題**：自動（跟隨系統）、淺色、大字切換；375px 四個分頁都沒有橫向捲動；底部分頁列為 fixed。
- **鍵盤**：Tab 聚焦 checkbox、空白鍵勾選，重新繪製後焦點保留；頁面中沒有 inline 事件屬性。
- 主控台沒有錯誤。
- 測試資料（localStorage、IndexedDB、OPFS）已清除，測試用 http 伺服器已停止。

**沒有實測**：真實的資料夾選擇視窗、真實 Google 雲端硬碟同步、以 `file://` 直接雙擊開檔（預覽窗不讓 file:// 載入）、實際送出列印／存成 PDF（只驗證列印區內容與 CSS）、手機真機與 iOS safe-area 實際外觀、真實 Open‑Meteo 網路回應（以 stub 測試）、IndexedDB 不可用時的後援模式（程式有處理，未模擬）、螢幕閱讀器朗讀。
