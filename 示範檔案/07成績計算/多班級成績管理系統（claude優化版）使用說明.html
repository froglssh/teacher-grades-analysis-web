🚀 立即開啟成績管理系統線上版

系統簡介與技術安全

日常教學中，老師們常常需要管理多個班級、不同科目，甚至要應對請假補考、個別特殊生加權配分、學期成績及格邊緣預警等複雜需求。傳統 Excel 往往公式繁雜、容易誤刪，而雲端資料庫又有學生個資外洩的隱憂。本系統專為解決這些痛點而生：

🔒 隱私與安全：100% 本地運算，絕無伺服器暫存
本系統為純前端單一網頁程式。所有學生名冊、成績數據皆儲存於老師自己電腦的瀏覽器中（IndexedDB / localStorage）或您自行指定的本機雲端硬碟資料夾。絕不上傳任何第三方後端伺服器，徹底符合個資保護法與校園資通安全規範！

⚡ 極速流暢登分

提供「依座號順序輸入」、「⚡ 快速登分（依考卷收回順序輸入）」與「連續模式」，登分不再眼花撩亂。

🎯 彈性多元評量

支援欄位自訂滿分（如滿分 50 或 20）、缺考（0分）與免計（按比例放大）、群組配分、去最低分或取最高分。

📊 專業統計與分析

一鍵產出班級平均、五標、盒鬚圖、Z/T 分數、自訂組距分布圖、性別比較與跨學期長期追蹤。

🖨️ 多樣化列印與匯出

支援列印完整班級成績冊，以及每頁兩張、含各項班平均與家長簽章欄的「個人成績通知單」。

🆕 4.0～4.3 重大升級特寫

系統經過歷次架構重構與教學現場實證，由 3.0 全面躍升至 4.3 旗艦版，帶來多項重磅技術革新：

📁 資料夾儲存與雙機共用 (v4.3)

透過 File System Access API 指定雲端硬碟資料夾，辦公室與筆電讀寫同一個正本檔案，自動衝突保護與 14 天歷史備份。

🔌 完全內嵌・離線可用 (v4.2)

已將 SheetJS (0.20.3) 與 Chart.js (4.4.1) 完整內嵌於單一 HTML 檔內，無網路的深山或封閉內網照常運行所有功能。

💾 IndexedDB 大容量儲存 (v4.1)

突破舊版 localStorage 5MB 限制，大班級多年級安心存放；內建啟動遮罩保護、自動還原點與多分頁同步鎖定。

🏷️ 智慧備份與操作提示 (v4.0)

頂端常駐「上次備份狀態標籤」與即時操作紀錄視窗，超過 7 天未備份自動變色提醒，名冊特殊字元全面安全跳脫。

📑 個人成績單列印 (v3.4)

每頁兩張精美個人成績單，直印上下、橫印左右，含各項成績、項目班平均、名次、家長簽章與個別評語欄。

📐 盒鬚圖與 Z/T 分數 (v3.4)

統計分析新增盒鬚圖（Boxplot）快速辨識離群值，並提供 Z 分數與 T 分數換算，常態化客觀評估學生進退步。

📁 雙機共用與資料夾儲存 (4.3 核心功能)

很多老師會在「學校辦公室電腦」與「家裡的筆電」交替登分。4.3 版新增指定資料存放資料夾（支援 Chrome、Edge 等基於 Chromium 的現代瀏覽器），徹底解決隨身碟拷貝容易覆蓋的困擾！

💡 運作機制與原理
系統透過瀏覽器的 File System Access API，讓網頁直接存取您指定的本機資料夾（例如 Google Drive 電腦版或 OneDrive 的本機同步資料夾）。資料夾內的 成績資料.json 為唯一正本，原本瀏覽器內的資料庫則作為本地快取與後援。

兩台電腦共用設定步驟

  1. 選擇儲存資料夾： 在辦公室電腦開啟系統，切換至「💾 匯出資料」分頁，找到「📁 資料存放位置」卡片，點擊 📁 選擇資料存放資料夾，選取您 Google Drive 或 OneDrive 在電腦上的同步資料夾（例如 我的雲端硬碟/成績檔案夾）。
  2. 首次建立或匯入： 若資料夾內原本沒有資料，系統會將目前的成績資料寫入建立 成績資料.json；若資料夾內已存在正本，系統會提示您載入正本。
  3. 第二台電腦連結： 回到家裡的筆電，開啟同一個系統網址，同樣至「💾 匯出資料」點擊「選擇資料存放資料夾」，選取同一個雲端硬碟同步資料夾即可！
  4. 瀏覽器存取授權： 依據瀏覽器安全性規定，重新開啟網頁時可能需要點擊授權；當 Chrome 出現「每次造訪都允許」時，建議勾選即可免除重複點選。

雙機共用的重要注意事項

⚠️ 雲端同步需要時間，請勿兩台電腦「同時」登分！
  • 換電腦前：先確認網頁右上角標籤顯示 📁 已同步到資料夾，並等待電腦右下角/右上角的雲端硬碟圖示同步完成（不再轉圈）。
  • 換電腦後：開機後先確認雲端硬碟已完成下載最新檔案，再開啟本網頁。
  • 衝突保護機制：若系統偵測到正本已被另一台電腦修改，會暫停寫入並主動彈出視窗詢問：
    1. 「載入資料夾內較新的資料」：改用另一台電腦的最新內容（本機未儲存的變更會先存成本機自動還原點）。
    2. 「以本頁內容覆蓋」：以本頁內容為準覆蓋，資料夾原本檔案會先自動備份為衝突檔。
    3. 「把本頁內容另存成衝突檔，之後再處理」：安全保存兩邊內容，稍後手動整理。
  • 每日歷史備份：每天第一次寫入時，系統會自動在該資料夾的 成績資料_歷史 子目錄備份一份 成績資料_年月日.json，自動保留最近 14 天的歷史檔案，隨時可一鍵還原！

1. 📥 匯入 Excel (多班級成績冊)

開學初或段考後，您可以直接上傳學校教務處發布的 Excel 成績冊，系統會自動完成多班解析與結構化建檔。

1. 已儲存的班級資料 (快速切換)

每次開啟網頁時，上方會列出所有已儲存在瀏覽器內的班級清單：

  • 學年與學期篩選：提供「篩選學年」與「篩選學期」下拉選單，能精準過濾不同學期的班級。
  • 一鍵進入成績表：每個班級卡片皆有 開啟 ↗ 按鈕，點擊立即跳轉到該班的成績登記表格。
  • 批次刪除與防呆：若需整理舊班級，可勾選後點擊「🗑 刪除勾選的班級」。所有被刪除的班級會先移入「最近刪除（垃圾桶）」，不怕誤刪！

2. 🏫 班級管理 (手動建班與名單更新)

除了直接匯入 Excel，您也可以手動建立班級或隨時修訂學生名冊：

1. 學年・學期・班級選取器

位於頁面頂部，與「成績管理」分頁即時聯動。在任一處切換班級，所有頁面與報表皆會同步切換。

2. 手動新增班級與學生名單

  • 輸入班級名稱（支援如「201 生物」、「高二數理資優班」等任意符號）。
  • 在「學生名單」文字框中，每行輸入一筆「座號 姓名」（例如 01 陳大同 男，性別選填），點擊 建立班級 即可完成。

3. 名單更新的「三層智慧配對」防護

🛡️ 轉學生、轉組或改名？成績絕不遺失
學期中若有學生轉入、休學、轉組或改名，直接在學生名單框修改後點擊「更新學生名單」。系統會依據：
第一層：座號與姓名皆相符 ➔ 成績完全保留。
第二層：姓名相同但座號改變（換座號） ➔ 成績自動隨學生移至新座號。
第三層：座號相同但姓名相近（改名） ➔ 提示確認後保留成績。
若有名單中的學生將被刪除且該生已有登記成績，系統會跳出醒目清單要求二次確認，嚴防誤刪。

3. ✏️ 成績管理與表格佈局

本分頁是平時登分與結算的核心工作台。採用針對高密度成績輸入優化的表格佈局：

右側五欄固定凍結

橫向欄位很多時，表格向右捲動，右側的關鍵計算欄位會固定停留在螢幕右側，讓您隨時掌握總評：

  • 目前累計：目前所有已評量欄位的加權實得總分（藍字）。
  • 初步成績：按目前已考欄位的權重比例，等比換算為 100 分制的即時成績。方便在學期中提早看出哪些學生處於不及格邊緣！
  • 加減分：全學期平時獎懲加減分（僅限整數）。在格子雙擊（Double Click）可開啟備註輸入理由，有理由的格子右上角帶有小黃點。
  • 學期成績：依完整配分公式計算之最終總成績（粗體深綠色，不及格紅字）。若完全沒有成績則顯示為空白，不會拉低平均。
  • 名次：班級即時排名，同分同名次，無成績者顯示「–」。

缺考 (缺/a) 與 免計 (免/e) 的精準計算

💡 缺考與免計的區別與規範
  • 缺考（輸入「缺」或「a」）：以 0 分 計算，格子呈現紅底粗體「缺」。該項配分仍計入分母，學期成績會受到影響。
  • 免計（輸入「免」或「e」）：該項目不納入計算，格子呈現藍底粗體「免」。系統會自動將其配分扣除，並把其餘項目的權重按比例等比放大至 100% 計算！
  • 取消標記：直接點擊該格輸入新分數，即可清除缺考或免計標記。

4. ⚡ 快速輸入與連續登分技巧

系統提供多種極速登分方式，適應不同批改場景：

1. 表格直覺鍵盤巡航

點選任一格子打分數：
• Enter：跳到本欄下一個空格（可在狀態列切換為「往下一列」）。
• Shift + Enter：往上一列。
• ↑ ↓ ← →：上下左右移動。
• Esc：取消修改還原原分數。只接受合法分數，誤按滾輪不會改動數值。

2. ⚡ 快速登分 (依考卷收回順序)

考卷常被打亂未按座號排？點擊「⚡ 快速登分」：
在輸入框直接打「座號 分數」（例如 15 88 或 15 缺）按 Enter，系統立即寫入並在右方紀錄歷史，同時即時列出尚未登分的座號清單！

3. 連續登分模式 (流水號登分)

考卷已照座號排好？在快速登分面板勾選「☑ 連續模式」並設定起始座號：
只要打分數按 Enter，立即寫入該生並跳下一位，面板以大字提示「下一位：06 李同學」；直接按 Enter 為跳過、打 b 可回上一位！

4. 從 Excel 貼上一整塊

在外部 Excel 選取一塊矩形分數區域複製（Ctrl+C），回到系統點選目標左上角第一格，按下 Ctrl+V，分數自動由該格往右、往下完整填入！

📋 批次貼上成績 (多欄智慧對位)

點擊頂部工具列「📋 批次貼上成績」，可一次勾選多個目標欄位：

  • 座號自動對位：若貼上的文字第一欄是座號，系統會自動比對學生座號填入，即使行數順序不一致也不會錯位！
  • 空白格保留原成績：貼上的資料中若有空白格，系統絕不會抹除原本已登的分數。
  • 寫入前預覽：貼上後會先列出「新增筆數、覆蓋筆數（顯示前 5 筆舊值 → 新值）、略過筆數」，確認無誤才正式寫入。

全域復原與重做 (Ctrl+Z / Ctrl+Y)

無論是不小心填錯整列成績、誤刪欄位、批次貼錯或更動配分，隨時按下鍵盤 Ctrl+Z（Mac 為 ⌘+Z）即可復原；各班擁有獨立的復原紀錄，換班再切回依然可以復原！

5. ⚖️ 欄位、配分與計算方式

1. 欄位選單「⋯」功能

每個成績欄位標題右上角皆有「⋯」選單按鈕，點擊可開啟功能選單：

  • 修改欄位屬性：修改欄位名稱、變更所屬群組、自訂欄位滿分、設定評量日期。
  • 同群組左右排序：點擊「← 往左移」或「往右移 →」，自訂欄位先後順序。
  • 加入平均欄：一鍵將該欄納入指定的平均計算欄。
  • 刪除欄位：刪除該欄（可按 Ctrl+Z 復原）。

2. 自訂滿分折算百分制

新增或編輯欄位時可設定「滿分」（預設 100，可改為 50、20 等）。非 100 滿分的欄位，標題下方會標註如「/50」；在結算學期成績時，系統會自動按 (實得分數 ÷ 欄位滿分) × 100 換算為標準百分制計算加權，不必老師手動換算！

3. 群組折疊與自訂分類

欄位可歸類為日常考查、期中考、期末考、作業、實驗、報告、報告或自訂群組。點擊表格頂部的群組色帶即可將該群組所有細項欄位「折疊」收合，只保留群組平均欄，讓表格更加清爽乾淨！

4. 建立平均欄位 (取最高 N 次 / 去最低 N 次)

點擊頂部工具列「☑ 選取欄位」，勾選多次小考或作業後，點擊「建立平均欄位」，可選擇：

  • 算術平均：所有勾選項目平均。
  • 去掉最低 N 次平均：自動剔除學生個人表現最差的 N 次後再平均（缺考 0 分優先剔除）。
  • 取最高 N 次平均：僅採計表現最佳的 N 次成績。

5-1. 👤 特殊生個別配分處理

資源班學生、身心障礙生、體育專長生或因公請假長期缺考的同學，評量加權比例往往與全班不同。本系統提供完善的個別學生配分設定：

  1. 在「成績管理」表格中，找到該位學生的姓名，點擊學生姓名旁的 配分 按鈕。
  2. 彈出該生的個別配分設定視窗，取消「使用班級預設配分」核取方塊。
  3. 直接輸入該生專屬的各項配分比例（例如將實驗考查 20% 移轉至平時作業）。
  4. 點擊儲存，該生的學期成績即刻依其專屬配分精準重算，名冊旁會顯示標記，列印總表時也會明確備註。

6. 📊 統計分析與教學應用

系統內嵌 Chart.js 4.4.1 圖表庫，提供三大維度的即時統計圖表：

1. 單一班級深度分析

• 敘述統計指標：平均數、中位數、標準差、最高分、最低分、及格率、前標/均標/底標。
• 分布長條圖：支援自由切換「10分組距」或「5分組距」，並附平均線與標準差標記。
• 盒鬚圖 (Boxplot)：一眼辨識四分位距（Q1/Q2/Q3）與極端離群值。
• Z 分數與 T 分數：客觀常態化數值，方便觀察個別學生在群體中的相對位置。
• 性別差異分析：男女生成績對比雷達/直條圖與平均差異。

2. 多班級橫向比較

同時任教多個同進度班級時，勾選多個班級進行橫向比較：
• 班級平均數與及格率對比柱狀圖。
• 各段考項目跨班難易度比較。
• 快速掌握各班教學進度與吸收落差。

3. 跨學期長期追蹤與預警

追蹤同一批學生在不同學期（如高一上 ➔ 高一下 ➔ 高二上）的成績演變：
• 學生個人升降軌跡折線圖。
• 自動列出「成績大幅退步」或「學期成績瀕臨不及格」之預警關懷名單，方便及早進行課後輔導或親師溝通。

7. 💾 匯出、備份與個人成績單列印

1. 個人成績通知單列印 (3.4 旗艦亮點)

期末或段考後要發給學生與家長簽章確認？在「列印成績」選項中選擇「個人成績單」：

  • 一頁兩張排版：直印時上下各一張，橫印時左右各一張，不浪費紙張。
  • 內容完整齊備：列出學生姓名、座號、各單項分數、各單項之全班平均、加減分與說明、學期成績及班級排名。
  • 親師溝通欄位：下方附有「家長簽章欄」與「導師勉勵與評語備註欄」，列印後即可直接裁剪發放。

2. 班級成績總表列印與 Excel 匯出

  • 列印班級成績總表：支援自由勾選要印出的欄位（可隱藏細項只印總分），格式符合學校存檔規範。
  • 匯出 Excel (.xlsx)：一鍵下載完整成績試算表，包含學生名單、各項原始得分、加權後學期成績、名次及加減分理由，中文完全不亂碼。

3. JSON 完整備份與還原

  • 下載 JSON 備份檔：一秒將所有學年、所有班級、個別配分、操作設定完整打包為單一檔案，妥善存於隨身碟或雲端硬碟。
  • 還原備份：在任何新電腦開啟本網頁，點選「還原 JSON 備份」，所有資料立即原樣復活！支援「覆蓋」或「與現有班級合併」。
  • 最近刪除（垃圾桶）：任何被刪除的班級或整個學期，皆會保留於最近刪除清單（最多 20 筆），提供「一鍵還原」後悔藥。

8. ✨ 成績示範與練習

新手老師剛使用系統想先熟悉介面？切換到「✨ 成績示範」分頁：

  • 內建 11 份完整示範班級（涵蓋 113 與 114 學年、第一與第二學期）。
  • 包含完整日常考查、段考分數、缺考免計示範、加減分備註與特殊生個別配分。
  • 點擊「匯入勾選的示範班級」即可練習登分、配分運算、統計圖表切換與個人成績單列印！

❓ FAQ 常見問題與疑難排解

我要如何在「辦公室電腦」與「家裡筆電」同步使用，資料才不會錯亂？
強烈建議使用 4.3 版的「📁 指定資料存放資料夾」功能！兩台電腦各自主動在「💾 匯出資料」中選擇相同的 Google Drive 或 OneDrive 同步資料夾。換電腦前，請先確認網頁右上角顯示「📁 已同步到資料夾」，並等待雲端硬碟同步圖示完成上傳；切記不要兩台電腦同時開著登分，即可享受自動同步！
沒有網路的環境（例如地下室或斷網電腦）可以使用嗎？
100% 可以！ 4.2 版已將 SheetJS (Excel 匯入匯出) 與 Chart.js (圖表元件) 完整內嵌在 HTML 單檔中。您可以直接把 HTML 檔案拷貝到隨身碟，在任何完全無網路的電腦上開啟，所有功能完全正常運作。
我不小心關閉瀏覽器，剛剛輸入的成績會遺失嗎？
不會！系統在您每次鍵盤敲擊、改配分或貼上時，皆會透過 IndexedDB 進行即時毫秒級自動儲存。即使直接關閉分頁或電腦突然重開機，下次開啟網頁時所有進度皆完整保留。
學生請假缺考，該填「0分」、「缺」還是「免」？
• 若該生無正當理由缺席、依校規以零分採計：請填「缺」（或英文字母 a），系統會以 0 分計算並在格子顯示紅底。
• 若該生經核准免測或病假免計、該次成績不列入學期考核：請填「免」（或英文字母 e），系統會顯示藍底，並將其配分扣除，自動將其他已考項目等比放大到 100%！
某次小考滿分是 50 分或 20 分，學期成績加權會不會算錯？
完全不會！點擊該欄右上角「⋯」選單，將「滿分」改為 50 或 20。系統在結算學期總成績時，會自動依 (實得分數 ÷ 欄位滿分) × 100 換算為標準百分制後再乘以配分權重。
不小心誤刪欄位或整批貼錯，要怎麼還原？
直接按下鍵盤 Ctrl+Z（Mac 為 ⌘+Z）即可逐步復原！系統支援逐格輸入、刪除欄位、改配分、群組配分、複製配分、批次貼上、名單更新等各類操作的全域復原。若誤刪整個班級，可至「💾 匯出資料」➔「最近刪除」中一鍵還原。
為什麼部分學生的空白格子會出現「黃色斜紋」？
黃色斜紋是系統的疑似漏登智慧提示！當該欄位全班已有超過一半的同學登入分數，但某位學生依然是空白時，系統會以黃色斜紋標示，提醒老師可能漏打分數或尚未登記請假補考。
