多班級成績管理系統 2.0

本系統是專為高中及中小學教師開發的「純前端、零負擔」多班級學期成績冊管理工具。能自動識別您的 Excel 分頁、動態計算日常與定期加權，並提供跨班比較與跨學期追蹤。

🚀 立即開啟成績管理系統線上版

系統簡介與技術安全

日常教學中，老師們常常需要管理多個班級、不同科目，甚至要應對請假補考、個別特殊生加權配分的需求。本系統旨在為老師提供一個簡便、強大且極度安全的成績管理方案。

🔒 隱私與資料安全聲明
本系統為純前端（Single Page Application）應用。所有您上傳的 Excel 成績單、學生名單以及您鍵入的成績，100% 儲存在您的本機電腦瀏覽器中（利用 localStorage 技術）。本系統沒有任何後端伺服器，絕不會將任何學生姓名或成績傳輸至外部網際網路，確保完全符合個資法規範，請老師們安心使用。

系統特色

  • 無痛銜接 Excel：支援直接拖放學校教務系統下載的成績冊活頁簿，自動識別多班級分頁。
  • 極度彈性的配分機制：除了一般加權，還支援「去掉最低 1 次 / 2 次」的小考平均欄位，甚至能為個別學生調整專屬配分。
  • 視覺化統計分析：自動生成常態分布曲線圖、跨班段考平均比較圖，以及沿革追蹤一個班級在不同學期的學習表現。
  • 專用 A4 列印樣式：一鍵輸出精美、工整的紙本成績單。

分頁說明：匯入 Excel

此分頁是您開始使用系統的起點，提供「從本機載入」與「匯入新檔案」兩大區塊。

1. 已儲存的班級資料

當您在瀏覽器中建立過班級後，每次開啟網頁，這些班級會顯示在此區塊中。您可以：

  • 使用 篩選學年 或 篩選學期 下拉選單快速篩選班級。
  • 勾選特定班級，並點擊 ▶ 載入勾選的班級，即可將這些班級載入工作區。
  • 對於舊學年或不要的資料，勾選後點擊紅色的 🗑 刪除勾選的班級（注意：此動作無法復原）。

2. 匯入新的 Excel 成績冊

如果您手邊有全新的 Excel 學生名單或成績冊，請在此匯入：

  1. 設定 學年（如 114）、學期（第一學期或第二學期）以及 科目名稱（如：生物）。
  2. 將 Excel 檔案拖曳至 點擊選擇檔案，或將 Excel 拖曳到這裡 的虛線框中，或點擊該區域選擇檔案。
  3. 系統會自動讀取 Excel 中的所有活頁分頁（每個分頁代表一個班級）。系統會智慧型分析：
    • 學生基本資料：自動定位「座號」與「姓名」欄位。
    • 欄位群組（簽名元素）：系統會自動根據欄位名稱判定其群組，例如小考歸入「日常考查」（綠色）、段考歸入「期中考試」/「期末考試」（藍色）。
  4. 在下方預覽清單中，勾選您要匯入的班級，點擊 匯入勾選的班級 即可完成。

分頁說明：班級管理

如果您沒有 Excel，或者想直接手動修改學生的座號、姓名及班級，請使用此分頁。

1. 選取班級

點擊選取您要管理的「學年」→「學期」→「班級」膠囊按鈕，下方的名單即會自動載入。

2. 手動新增班級

若要手動新增一個班級，請輸入 班級名稱（例：`204 生物`）、學年 與 學期，然後點擊 新增班級 即可建立一個沒有學生的空白班級。

3. 編輯學生名單

大文字框會載入目前班級的學生名單，格式如下：

01 王小明 02 李小華 03 張大同
  • 您可以直接在此文字框中新增、修改或刪除學生姓名。
  • 支援直接從 Excel 複製兩欄（座號、姓名）並貼上於此。
  • 修改完畢後，請務必點擊 更新學生名單 進行儲存。
  • 如果您想徹底移除該班，可點擊 刪除此班級。

分頁說明：成績管理 (核心輸入與配分)

這是您日常教學最常使用的核心介面。包含班級選取器、成績表表格，以及上方強大的工具按鈕。

💡 成績計算邏輯與加權配分（重要！）
每個欄位（如小考 1、期中考）的標題下方都有一個配分比例輸入框（%）。系統計算「加權成績」時，會將各項成績乘以其配分比例。
例如：日常考查配分合佔 40%、期中考 30%、期末考 30%。學期加權總分為這三部分成績加權相加的結果。

表格結構介紹

表格分為固定列與成績欄位，表頭由群組色帶區分：

  • 日常考查（綠色）、期中考試（藍色）、期末考試（深藍） 等群組色帶與配分，能清晰指引老師目前欄位的屬性。
  • 學期加權成績：為系統精確到小數點後的真實加權平均。
  • 學期成績（加權後四捨五入）：最終登錄成績系統之四捨五入整數。低於 60 分（不及格）時，該格背景會自動呈現淡紅色作為預警。
  • 調整成績欄（藍色輸入框）：如果老師想要在加權後手動幫特定學生加減分數（如日常表現優異），可直接在該生的「調整」格輸入加減分（如 `+2` 或 `-1`），系統將自動累加至學期成績。

功能詳解：表格頂部工具欄按鈕

在成績表格的上方，有一排強大的快捷工具，操作邏輯與功能如下：

1. ☑ 選取欄位 與 建立平均欄位

  • 操作方式：點擊 ☑ 選取欄位，表格表頭會出現勾選框。勾選多個成績欄位（如小考1 ~ 小考5），上方的 建立平均欄位 按鈕便會浮現。
  • 計算方式：
    • 全部平均（空白不計）：只對有分數的項目進行平均。
    • 去掉最低 1 次 / 去掉最低 2 次：適用於多次小考，系統會為每位學生自動挑出分數最低的 1 或 2 次排除後再做平均。若學生請假次數多於排除限制，則會以剩下的次數計算。
  • 意義：幫助老師快速生成一個「小考平均」或「平時作業平均」的獨立欄位，並賦予該平均欄位一個總配分比重（如 20%），精簡成績冊版面。

2. 🗑 刪除欄位

點擊 🗑 刪除欄位 後，每個成績欄位標題旁會出現紅色 [✖] 按鈕，點擊即可刪除該欄位。再次點擊此按鈕可關閉刪除模式。

3. ＋ 新增欄位

點擊後開啟控制面板，可輸入欄位名稱、指定考查群組，並設定初始加權比例。

4. 📋 批次貼上成績 (高效輸入)

  • 情境：老師在其他 Excel 檔案登錄了成績，不想一筆一筆輸入。
  • 操作：勾選要貼上的目標欄位（可多選），在文字區直接貼上從 Excel 複製的整直行成績（一列對應一位學生），點擊匯入即可一次完成數十人的成績輸入！

5. ⚖ 複製配分到其他班級 (一鍵同步)

當您帶多個班級且使用相同的評量比例時，不需要在每個班級手動輸入比例。點擊此按鈕，可將本班各欄位的配分比例（%）以及平均欄位設定，一鍵複製並套用到同一年段的其他班級。

6. ⬆ 上傳成績檔 (段考/平時成績匯入)

當教務處發放了段考 Excel 成績單，或您從線上測驗系統導出了小考成績：

  • 點擊按鈕，上傳 Excel 檔案。
  • 系統會嚴格執行「座號 + 姓名」雙重比對，確保成績準確填入本系統對應的學生格內，並會詳細標示成功配對、部分不符或無此學生的清單，避免張冠李戴。

7. 顯示大小與高度調整

提供 ＋ 和 － 按鈕，可自由放大或縮小表格（70% ~ 130%），或調整表格視窗的高度（vh），適應不同尺寸的螢幕或投影機展示。

進階功能：個別學生配分 (特殊生處理)

在實際教學中，常有學生因長期公假、生病缺考、或是轉學生，無法參與某些考試項目。本系統特有「個別學生配分」功能，完美解決此困擾。

操作步驟：

  1. 在成績管理表格中，找到該位學生的姓名旁，點擊紫色的小字標籤 個。
  2. 將會彈出「個別學生配分設定」視窗。
  3. 在「個別配分（%）」欄位中，針對該生輸入專屬的配分比例。
  4. 點擊 儲存個別配分 即可。
ℹ 計算規則說明
  • 若該生某個欄位的個別配分設為 0% 或留白，則表示該欄位對該生使用「班級預設配分」。
  • 設定個別配分後，該生姓名旁的 個 按鈕會變為實心紫色，方便識別。
  • 系統在計算該生學期成績時，會以其「個別配分」為準，其餘學生的成績計算與權重完全不受影響。

分頁說明：統計分析的教學意義

本分頁提供強大的視覺化分析，協助教師發掘學習落差、掌握教學成效。

1. 單一班級分析

選擇班級與統計依據（如學期成績），系統會自動計算：

  • 基礎統計量：全班人數、平均分數、最高分、最低分、及格人數、不及格人數與及格率。
  • 成績分布直方圖（左圖）：直觀展示 90分以上、80~89分...等各分數段的人數比例。教學意義：若呈現雙峰分布，代表班級學習產生兩極化，需實施差異化教學。
  • 考試項目平均折線圖（右圖）：對比該班日常考查、期中考、期末考等各主要群組的平均分起伏。教學意義：若期末考平均大幅下降，代表期末課程難度提高或學生複習不足。

2. 多班級比較

勾選多個同一年級的班級，系統會產生**跨班級平均分柱狀圖與表格**。

  • 教學意義：老師可以直觀地看出自己帶的 301 班、302 班在同一次段考中的表現落差。若某班平均顯著落後，可及時調整該班的授課進度或引導方式。

3. 長期追蹤

當班級從高二升高三，或從第一學期進入第二學期，學生名單大致不變但班級名稱變更時：

  • 操作：勾選不同學期的沿革班級（如 113-1-201 班與 113-2-201 班），點擊產生長期分析。
  • 教學意義：系統會自動對比每位學生在不同學期的加權成績，畫出長期趨勢折線圖。能幫助老師實施**「早期預警」**，找出成績持續下滑、需要關懷或輔導的學生名單。

分頁說明：匯出、列印與資料備份

完成一學期的成績登錄後，您需要將成績資料儲存或交給學校系統。

1. 匯出成績與列印

  • ⬇ 下載班級成績：一鍵將當前選取班級的完整成績表格下載為 Excel 檔案，方便您直接上傳至學校的行政系統。
  • 🖨 列印班級成績：開啟專為紙本設計的列印視窗，格式工整並包含基本統計量。建議在列印設定中勾選「顯示背景圖形」，以確保群組色帶與不及格淡紅色標示能完美列印。

2. 還原與備份 (重要安全保護)

⚠ 瀏覽器清除快取風險宣導
由於資料儲存在瀏覽器的 `localStorage`，若您執行了瀏覽器清理（如：清理 Cookie、清除歷程記錄、重設瀏覽器），或是使用他人電腦的無痕視窗，儲存的成績資料將會遺失！

為避免上述情況導致心血白費，系統提供：

  • ⬇ 下載 JSON 備份：定期（如每次段考登記完）點擊此按鈕，會下載一個包含您所有班級、所有學期成績的 `.json` 備份檔。請將此檔案妥善保存在您的隨身碟或雲端硬碟。
  • ⬆ 還原 JSON 備份：在新電腦或瀏覽器被清空時，點擊此按鈕並選取您的備份檔，即可 1 秒還原所有歷史成績資料。

分頁說明：成績示範與練習

為了方便新使用者快速熟悉系統，系統內建了 11 份完整的示範班級成績檔。

  • 您可以直接勾選如 `113學年第一學期 201 生物` 或全選，然後點擊 ▶ 匯入勾選的示範班級。
  • 練習建議：
    • 匯入 113 學年與 114 學年的示範班級後，切換到「統計分析」→「長期追蹤」，勾選 `113-1-201`、`113-2-201`、`114-1-301`，觀察學生在兩年內的成績升降軌跡。
    • 練習在「成績管理」中修改示範學生的分數，體會即時加權計算的便利性。

FAQ 常見問題與疑難排解

如果學校的 Excel 成績單格式跟系統不符，要怎麼匯入？
系統在匯入 Excel 時，具有高度的容錯力。它會自動在表格中尋找含有「座號」、「姓名」的欄位。如果您的 Excel 格式比較特殊，建議您可以使用「班級管理」手動建立學生名單，再使用「成績管理」頂部工具欄的「批次貼上成績」或「上傳成績檔」功能，將成績快速複製進來。
我不小心關掉網頁，剛剛輸入的成績會不見嗎？
不會。本系統在您輸入成績、修改配分或名單時，皆會即時自動儲存至瀏覽器中。您也可以在成績管理中點擊「手動儲存」確保安全。只要您不主動清除瀏覽器快取，下次開啟同一網址時資料依然會在。
我想把成績分發給學生看，可以只列印個別學生的成績嗎？
在點擊「列印班級成績」時，會彈出列印選項面板。您可以選擇列印「完整成績冊」，或者在「統計分析」分頁中觀察學生的個人表現。如果您只需要個別學生的成績，建議將資料導出為 Excel 後，在 Excel 中進行篩選與分發。
有些學生的名字有罕見字，在 Excel 匯入時出現亂碼怎麼辦？
本系統採用現代的 `SheetJS` 庫解讀 Excel，對 UTF-8 與罕見字有良好的支援。若真的出現亂碼，您可以隨時在「班級管理」分頁的學生名單中，直接手動修正學生的姓名，並點擊更新即可。
