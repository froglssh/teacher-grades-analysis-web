使用說明（點擊展開）

1. 匯入 Excel 成績冊

  • 在「匯入 Excel」分頁選擇成績冊檔案（支援 .xls / .xlsx），系統會自動偵測每個班級分頁的學生名單與成績欄位結構（日常考查、期中考試、期末考等）。
  • 成績冊是空白的：產生對應結構的空白成績輸入表，欄位與原檔一致。
  • 成績冊已有成績：成績會按原格式一併匯入。
  • 「平均」「﹪」「學期成績」等計算欄不會被當成輸入欄匯入，由系統自動計算。

2. 配分與平均欄位

  • 每個成績欄位上方有「配分」框（％），學期成績 = Σ(各欄成績 × 配分%) + 加減分。配分為 0 的欄位（如個別小考）只做紀錄、不直接計入。學期成績低於 60 分會以紅色標示。
  • 點「選取欄位」進入選取模式 → 勾選多筆小考（或作業）→「建立平均欄位」，系統會新增一個自動計算的平均欄（黃底），可設定其配分比例，並可選擇「去掉最低 N 次」。
  • 平均欄會即時隨來源成績更新；空白成績不列入平均計算。表格過寬時可用工具列的「顯示大小」調整文字與列高，或用「高度」調整成績表格視窗長度。

3. 統計與長期追蹤

  • 統計分析有三種模式：單一班級（各項目分布與班平均）、多班級比較（選多個班＋特定考試項目）、長期追蹤（同名班級跨學年學期趨勢）。

4. 其他

  • 「刪除欄位」模式可移除欄位，欄位名稱與配分隨時可改；總配分非 100% 時會以紅色提醒。
  • 批次貼上：可一次勾選多個欄位，直接貼上從 Excel 複製的多欄成績資料。
  • 所有學年學期資料自動儲存於瀏覽器；可勾選指定班級下載 Excel，也可下載 JSON 備份並還原回系統。

統計分析

勾選多個班級（同一學年學期），可比較各班在「學期成績」或「特定考試項目（如期中考、期末考、平均欄）」上的表現。

先勾選你要視為同一個班級沿革的班級資料。系統會先檢查各班學生姓名是否一致；若差異過大，會提醒你可能選錯班級。

⚖ 複製配分到其他班級

將來源班級每個欄位的配分（%），依「欄位名稱」對應套用到目標班級。名稱相同的欄位才會被套用。

⬆ 上傳成績檔匯入

支援多班級分頁的 Excel（.xls/.xlsx）。系統會自動辨識每個分頁的「座號／姓名」與成績欄位， 並嚴格比對座號與姓名，確保匯入正確班級的正確學生。
