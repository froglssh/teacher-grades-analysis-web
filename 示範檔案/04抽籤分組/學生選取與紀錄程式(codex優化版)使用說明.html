學生選取、分組與紀錄程式使用說明v3.0

臺北市立麗山高中林獻升老師製作。上課隨機抽人回答、記錄加減分與表現備註、快速分組，並把每個班級的紀錄長期保存、匯出成 Excel／PDF。

快速開始（第一次使用約 3 分鐘）

  1. 班級與名單新增班級，貼上名單或匯入 Excel（可一次匯入多個班）。
  2. 課堂抽籤按「🎲 抽籤」或直接點學生，當場加減分、寫備註。
  3. 分組安排設定每組人數，按「隨機分組」，再拖曳微調。
  4. 統計輸出看全班被抽次數與分數，下載 Excel／PDF 或列印。
  5. 資料與備份選一個雲端硬碟資料夾，讓資料長期保存。

畫面最上方一直顯示目前班級選單，換班上課時直接切換即可；每個班級的名單、紀錄與分組都分開保存。五個步驟標籤會顯示目前狀態，例如「本輪 12/30」。

每天上課只需要：頁首選班級 → 步驟 2 按 🎲 抽 N 人 → 在紀錄上按 ＋／− 給分。所有操作都會自動儲存，不用再按「儲存」。

1班級與學生名單

我的班級

  • ＋ 新增班級：輸入班級名稱（例如「201」或「高二生物 A」）。頁首「目前班級」選單最下方也可以新增。
  • 點班級卡片＝切換到這個班；✎ 改名；🗑 刪除（會先確認、自動留還原點，6 秒內可按「復原」）。
  • ✨ 載入兩個示範班級：研習或第一次試用時使用。

方法一：貼上名單

每行一位，格式「01 王小明」或只寫姓名；可以直接從 Excel 複製「座號、姓名」兩欄貼上。

按鈕作用
建立為新班級用貼上的名單建立一個新班級（會詢問班級名稱）。
更新目前班級名單換成新名單。同名學生的紀錄會保留；新名單沒有的學生從名冊移除，但過去紀錄仍留在統計中。

方法二：匯入 Excel／CSV

  1. 切到 Excel 匯入，點選或拖曳檔案進來。
  2. 程式會列出每個分頁、偵測到的人數與前幾位學生。一個分頁＝一個班級，分頁名稱就是班級名稱。
  3. 同一分頁裡若有好幾班（座號又從 1 開始），會自動拆成「分頁名-1」「分頁名-2」。
  4. 勾選要匯入的分頁，按 匯入勾選的分頁為班級。遇到同名班級時可選「更新名單（保留紀錄）」或「另建新班級」。

「欄位判斷方式」通常用「自動判斷」即可；若座號姓名抓錯，改選「前兩欄為座號、姓名」或「只匯入姓名欄位」，列表會立即重新偵測。說明頁、封面等沒有學生的分頁會顯示「找不到學生」，不會被匯入。

班級名冊

  • 上方可一位一位新增（座號＋姓名，按 Enter），座號會自動往下遞增。
  • 🚫 標記今天缺席：不會被抽到，分組時也會排除；全部出席 一次恢復。
  • ✕ 從名單移除（可復原）。每位學生下方小字顯示「被抽 N 次・累計分數」。

手動點名

分組設定（左側）

5資料與備份

頁首的 💾 已儲存 標籤表示資料已寫入這台電腦的瀏覽器（IndexedDB）。每次修改 0.3 秒內自動儲存，關閉分頁時也會立即寫出。

只存在瀏覽器裡的資料，在清除瀏覽器資料、換電腦、換瀏覽器時會看不到。請務必設定下面的「長期存放資料夾」或定期下載 JSON 備份。

建議：選擇長期存放的資料夾（Chrome／Edge 電腦版）

  1. 到「資料與備份」按 📁 選擇資料存放資料夾，選 Google 雲端硬碟裡的一個資料夾。
  2. 程式會建立 學生選取分組資料.json，之後每次修改約 2 秒內自動寫入，頁首顯示 📁 已同步到資料夾。
  3. 每天第一次寫入前，前一版會備份到 學生選取分組資料_歷史 資料夾（保留 14 份）。
  4. 下次開啟時會自動連回資料夾；若瀏覽器要求重新授權，頂端會出現黃色提示列，按 連接資料夾 即可。

學校、家裡兩台電腦共用

  1. 兩台電腦都安裝 Google 雲端硬碟電腦版，並用 Chrome 或 Edge 開啟本程式。
  2. 第二台電腦選同一個資料夾，程式會自動讀入資料。
  3. 回到頁面時若另一台電腦已更新，頂端會提示 載入最新資料。
  4. 兩邊都改過時會請你選擇要用哪一份；沒被選用的一份會另存成「衝突檔」或還原點，不會遺失。

自動還原點與 JSON 備份

  • 自動還原點：每天 1 份（留 7 天），另外在刪除班級、更新名單、Excel 匯入、匯入 JSON、還原、重設前各存 1 份（留 10 份）。可在本頁還原或下載。
  • 下載 JSON 備份（全部班級）／匯入 JSON 備份…：匯入 v3 備份會取代全部資料；匯入舊版（v2）的備份檔則會新增為一個班級，不影響其他班。
  • 清除全部資料並重設：清除前會自動留還原點。

常見問題

舊版的資料還在嗎？

在。第一次開啟 v3 時，程式會自動把舊版存在瀏覽器裡的所有班級（名單、選取紀錄、加減分、分組、自訂快速備註）轉成新格式，並顯示「已將舊版資料搬到新版」。舊版資料本身不會被刪除。

要按「儲存」嗎？

不用。所有操作都會自動儲存；頁首的 立即儲存 只是讓你在關機前安心按一下。

按錯了怎麼辦？

刪除紀錄、移除學生、刪除分組或班級後，畫面下方會出現 復原 按鈕（6 秒內有效）。超過時間可到「資料與備份」用自動還原點回復。

學生改名或座號打錯，紀錄會不見嗎？

不會。v3 每位學生都有自己的內部編號，用「更新目前班級名單」或 Excel「更新名單」時，同名學生會沿用原本的紀錄。

為什麼有些學生一直沒被抽到？

請確認「本輪不重複」與「公平模式」都已勾選；到步驟 4 個人統計可以看到「從未被抽到」的人數，必要時直接點名他們。

學校網路擋外部網站時？

抽籤、分組、統計與儲存都能離線使用；Excel 匯入／匯出與 PDF 需要從網路載入元件，若無法使用請改到可上網的電腦操作。
