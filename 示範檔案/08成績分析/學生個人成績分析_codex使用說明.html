🔑 步驟一：查詢與準備你的成績

📱 成績查詢方式：
在開始輸入前，請先透過以下方式查出你想要分析的段考或模擬考成績：
  1. 使用手機登入「酷課 APP」，點選成績查詢。
  2. 或者使用手機/電腦登入學校的「校務行政系統」，查詢各科成績與班級、類組排名。
  3. 將成績記下來，準備手動輸入到本系統中。

二、輸入基本資料與成績

  1. 填寫基本資料： 在「學生基本資料」區，輸入你的姓名、班級、座號與學年度。
  2. 新增考試記錄：
    • 系統預設有一筆考試欄位。若要輸入多次考試（例如：第一次段考、第二次段考、模擬考），點選下方綠色的 ➕ 新增考試記錄 按鈕。
    • 選擇本次考試的類型，並輸入你的「班級排名」與「類組排名」（若有）。
  3. 手動輸入各科成績：
    • 在各個科目格子中，手動輸入你剛才查到的成績分數。
    • 系統預設包含國文、英文、數學、物理、化學、生物、地科、歷史、地理、公民等科目。
    • 增減科目： 若你的考試科目與預設不同，可點擊科目區最後的 − 刪除科目 勾選要移除的科目（可一次多科）；若有其他科目（如：資訊科技、美術），可點擊 ＋ 新增科目 自行輸入新增。
  4. 開始分析： 輸入完成後，點選藍色的 📈 開始分析 按鈕，系統就會立即為你生成分析報告。

💡 老師／導師使用：匯入全班 Excel（可得到班級相對分析）

  1. 點 📥 匯入全班 Excel，可一次選取多次考試的全班成績檔（.xlsx，需含「座號」「姓名」與各科欄位；表頭上方若有「114學年度 上學期 第一次段考」等文字，系統會自動辨識學期與考試名稱）。
  2. 匯入後會跳出學生清單，點任一位學生的 📊 查看報告 即自動帶入歷次成績並完成分析。
  3. 系統會用學期＋考試名稱＋姓名／座號，把這位學生的每次考試對應到全班成績檔，並在「🏫 班級相對位置」分頁顯示與同學比較的結果。
只有手動輸入個人成績、沒有匯入全班 Excel 時，系統只能做「和自己比」的分析；「🏫 班級相對位置」分頁會顯示提示，行動計畫的目標也會改用及格線與個人最佳成績。

三、如何看懂分析報告？

點選「開始分析」後，下方會出現多個分頁，點擊分頁標籤可切換檢視：

  • 📊 總覽：
    • 能力雷達圖： 越往外擴展代表分數越高，方便一眼看出你的強科與弱科。
    • 各科平均成績與分布： 讓你了解自己各學科的整體表現。
  • 🔍 單次考試分析： 選擇特定一次的段考，檢視該次考試的所有學科詳細統計與表現。表中的「Z／T（相對自身）」是和你自己這次各科平均比較，用來看偏科；要和全班比較請看下一個分頁。
  • 🏫 班級相對位置（v5 新增，需匯入全班 Excel）：
    • Z 分數＝（你的分數 − 班平均）÷ 班標準差。Z = +1 約在班上前 16%，Z = −1 約在後 16%。T 分數＝50＋10Z。
    • PR（班內百分等級）＝（分數比你低的人數＋同分人數÷2）÷ 班級人數 × 100。PR 70 代表約贏過班上 70% 的同學。
    • 五標位置與下一個標竿：頂標／前標／均標／後標／底標採大考中心定義（第 88／75／50／25／12 百分位），並告訴你「還差幾分」到下一個標竿。
    • 各科班內 PR 走勢：粗黑線是各科 PR 平均。PR 往上才是真的在同學中往前，不受考題難易影響。
    • 原始分數 vs 相對位置：例如分數 +8 但 PR −10，代表這次考題變簡單、同學進步更多，其實是相對退步；分數下降但 PR 上升，則代表考題變難、你其實表現更好。
    範例：同樣考 70 分，在班平均 60 的科目是強項（Z 為正），在班平均 80 的科目卻是弱項（Z 為負）。用 Z 與 PR 才能公平比較各科強弱。
  • 📈 多次成績分析：
    • 當你輸入兩次以上的考試後，這裡會繪製出「各科成績變化趨勢折線圖」以及「排名變化曲線圖」。
    • 線條向上代表成績進步，向下的話則需要多加注意囉！這能幫你追蹤自己的成長軌跡。
    • 排名變化圖：越上方代表名次越前面。
    • 上學期 vs 下學期（v5 新增）：同時輸入兩個學期的考試時，會列出各科學期平均與變化。
  • 🧠 進階分析：
    • 線性趨勢與下次預測：除了預測分數，v5 加上「95% 預測區間」，代表下次分數大概會落在的範圍；區間越寬，代表成績起伏越大、預測越不確定。
    • 科目相關性矩陣：數字旁有 * 才是統計上有意義的相關。考試次數少時（例如 6 次），|r| 要大於約 0.81 才算數，沒有 * 的相關多半只是巧合。
  • 🎯 優劣勢與策略：
    • 系統會自動將你的科目分為「強勢學科」與「待提升學科」。
    • 針對不同特性的學科，系統會給予你「具體的讀書策略與時間分配建議」，例如如何分配複習進度、如何調整學習方法等。
    • 📅 下次考試行動計畫（v5 新增）：依最近一次考試，為每一科給出診斷與目標：
      診斷條件
      🔥 優先補強未及格，或落後班平均 1 個標準差以上
      ⚠️ 及格邊緣60–64 分，下次容易滑落
      📈 提升潛力低於班平均（沒有全班資料時：低於自己的歷次平均）
      ✔️ 穩定表現穩定，可挑戰更高標竿
      💪 優勢班上前段（Z ≥ 1），維持即可
      「下次目標」優先採用你在 🎯 目標追蹤 自己設定的分數，其次是班級的下一個五標，最後才是及格線或個人最佳。系統也會算出每科建議的讀書時間比例，以及「若各科都達標，平均與班排可以到哪裡」。

四、資料保存與備份

為了保護隱私，本系統不會上傳任何資料到伺服器，資料只保存在你目前使用的瀏覽器中。如果你換了手機或清除瀏覽器快取，資料可能會消失，因此請善用以下功能：

  • 💾 儲存資料： 點擊後，資料會保存在此瀏覽器的 Local Storage 中，下次用同一個瀏覽器打開會自動載入。
  • 📂 載入資料： 手動載入你之前在該瀏覽器儲存的成績。
  • 📤 匯出原始資料： 點擊後會下載一個 .json 檔案，這是你的成績備份檔，請妥善保存。
  • 📥 匯入原始資料： 當你換了新手機或瀏覽器時，可點選此按鈕並選取你的 JSON 備份檔，成績便會立刻全部還原！
  • 📄 匯出完整 PDF 報告： 點選此按鈕可以將你美美的成績分析圖表與策略建議（含班級相對位置與下次考試行動計畫），列印出來或下載存成 PDF，方便拿給家長、老師或自己收藏！

五、常見問題 FAQ

1. 為什麼我的雷達圖看起來圓圓的沒有起伏？

可能是因為你所有科目輸入的分數都非常接近。通常各科分數有高低起伏時，雷達圖就會呈現明顯的多邊形，指出你的優勢方向。

2. 怎麼移除已經新增的考試？

在每次考試記錄的標題列右側，點擊紅色的 ✕ 移除 即可刪除該次記錄；旁邊的 ⧉ 複製 可快速複製一筆考試。

3. 輸入成績時，如果缺考該怎麼辦？

如果該科缺考，可以直接將該格分數留空，系統在分析時便會自動忽略該科，不會影響其他科目的平均計算。

4. 為什麼「🏫 班級相對位置」沒有資料？

這個分頁需要老師匯入的全班 Excel。請確認：(1) 已匯入同一次考試的全班成績檔；(2) 你的姓名與 Excel 上一致；(3) 考試的學期與名稱（如「上學期 第二次段考」）與 Excel 相同。

5. 分數進步了，為什麼 PR 反而下降？

代表這次考題比較簡單，全班平均進步得比你多。PR 看的是「你在同學中的位置」，比原始分數更能反映真實的進退。
