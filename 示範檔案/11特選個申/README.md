# 高三升學輔導｜升學路徑工作室（人機協作優化版）

繁體中文、純前端的高中升學申請輔導工作桌，專門服務臺灣高中「特殊選才」與「個人申請」準備。無需安裝任何額外套件或建立後端伺服器，資料 100% 保留在使用者本地瀏覽器。

本版本全面導入**人機共創（Human-AI Collaboration）**深度設計：透過各欄位「快捷關鍵字點選」、「先問 AI 靈感發想」、「三大主流 AI（全面加入 Claude、ChatGPT、Gemini）」、多模式精修提示詞與一鍵示範資料，徹底告別面對空白文字框的無所適從，讓每位學生都能有效率地將真實高中探究轉化為有說服力的升學路徑。

---

## 🌟 本次升級亮點與核心功能

### 1. 100+ 關鍵字標籤快速點選（Quick Tags）與起手句（Sentence Starters）
- **關鍵字標籤庫**：在每個要填寫的項目前方提供大量精選標籤（涵蓋生醫、AI、環境、材料、認知、探究角色、硬核證據、深度反思等），點擊即可自動帶入或以頓號串聯，給予學生即時靈感。
- **句型引導起手式**：提供標準探究敘事、問題意識、STAR（情境/任務/行動/結果反思）架構起手句，點擊直接置入文字框，降低撰寫門檻。

### 2. 「✨ 先問 AI 靈感」欄位引導彈窗（AI Inspiration Explorer）
- 學生在填寫任何欄位前，若缺乏具體想法，可點擊該欄位右上角的 **「✨ 先問 AI 靈感」**。
- 系統自動結合**目標校系**、**當前欄位**與**已選關鍵字**，產生專屬引導提問 Prompt，並提供第一線升學輔導專家的「避坑與審查建議」。
- 支援一鍵複製並直接跳轉 **Claude ↗**、**ChatGPT ↗**、**Gemini ↗** 探詢建議，獲取靈感後再回到網頁填寫。

### 3. 全面支援 Claude 查詢與串接
- 除了 Google 搜尋、ChatGPT、Gemini 外，**全面新增 Claude 支援**（包含目標校系卡片、階段二備審規劃、階段三筆面試練習、各欄位探索視窗）。
- 點擊「Claude 提問 ↗」自動開啟 `https://claude.ai/new`，並同步將精心調校的提示詞複製到剪貼簿，直接按 `Cmd+V` / `Ctrl+V` 即可對話。

### 4. 填寫後多模式人機共創優化（Post-filling Refinement）
- **單欄專屬優化**：每個輸入框下方提供 **「🤖 複製此欄給 AI 優化」**，針對該單一欄位草稿產生包含 STAR 架構與防杜空泛的精修 Prompt。
- **階段二多模式切換**：
  - **模式 1【備審素材架構與缺口診斷】**：先查校系規格與缺口清單（原版教練提示詞）。
  - **模式 2【文句潤飾與 STAR 精煉】**：填寫後給 AI，強調保留高中生第一人稱真實語氣，修飾流水帳為精準有力文字。
  - **模式 3【審查委員挑刺與盲點挑戰】**：以嚴格大學教授視角，挑出脆弱主張、模糊角色與面試追問清單。
- **階段三模擬面試多模式演練**：
  - **模式 1【三輪追問式模擬面試】**：依序進行「診斷題 → 追問題 → 情境題」，嚴守「一次只問一題、給予三維度回饋、不直接給標準答案」之升學輔導金律。
  - **模式 2【MMI 跑站倫理與兩難情境題】**：專攻醫學/生醫/跨領域學群之兩難情境判斷。
  - **模式 3【一分鐘自我介紹黃金架構】**：Hook (開場亮點) + Highlight (探究成果) + Fit (校系契合度)。
- **AI 建議暫存與對照盒（Compare Box）**：
  - 提供可收合的對照筆記盒，方便學生將 AI 給予的建議、精修示範或面試問答貼在此處，一邊對照一邊在原欄位調整自己的草稿。

### 5. 「✨ 一鍵載入完整示範資料」（Demo Dataset）
- 頂部導覽列提供 **「✨ 載入示範資料」** 按鈕。
- 一鍵帶入「國立臺灣大學生命科學系（特殊選才）」與「國立成功大學生物醫學工程學系（個人申請）」的完整真實範本（涵蓋問題意識、專題角色、手寫實驗日誌證據、挫折反思、推薦信事實、模擬面試記錄）。
- 讓首次接觸的學生或研習現場教師在 1 秒內看到完整典範長相，隨時可修改為自己的內容或清空。

### 6. 即時字數統計與整體填寫進度指標
- 每個文字輸入框即時計算字數（如 `245 字`）。
- 頂部動態顯示填寫進度標章（`填寫進度 78%`），依完成度智慧變換色彩，激勵學生逐步推進。

## 使用方式

1. 可直接以瀏覽器開啟 `index.html`。
2. 若剪貼簿受本機檔案限制，可在本目錄手動執行：
   ```bash
   python -m http.server 4173 --bind 127.0.0.1
   ```
   再以瀏覽器開啟 `http://127.0.0.1:4173`。

## 本機資料限制與救援機制

- **儲存範圍與限制**：資料儲存在使用者目前瀏覽器的本機儲存空間（`localStorage`，金鑰為 `admissions-studio-v1`，資料結構版本 `version: 2`）。本網站不會自行上傳表單資料至任何雲端伺服器；切換裝置或清除瀏覽器資料前，請定期點擊「匯出我的資料備份」保存 JSON 檔。
- **壞資料防護與本機救援**：載入時若偵測到本機資料損壞（無法解析之 JSON）或結構不相容，系統會立即於頁面頂部顯示具螢幕閱讀器語意（`role="alert"`）之警示橫幅，並**主動停止自動儲存**，避免以空白預設狀態覆寫原始內容。使用者可透過警示橫幅上的按鈕選擇「下載原始損壞字串（.txt 救援）」以提取內容修復，亦可複製損壞文字或重設開新檔案。
- **儲存與清除失敗回饋**：當儲存配額額滿或瀏覽器安全性限制導致寫入失敗時，頂部狀態會明確顯示「本機儲存失敗」並以提示訊息警示，絕不誤報儲存成功；執行「清除本機資料」若遭遇刪除失敗亦會即時回饋錯誤，不假稱清除完成。

## 個資保護、授權隔離與使用界線

- **本機資料與外部服務**：系統無後端資料庫，不會自行呼叫外部 AI 服務。姓名（或代號）與高中／班級的獨立欄位不會自動加入 Google 搜尋字詞、Claude／ChatGPT／Gemini 提示詞或外部網址。**自由文字不會自動匿名化**；每次開啟外部服務或複製前，須逐次檢視完整預覽，自行移除可識別／敏感資料。
- **學習經歷明確授權與獨立性**：
  - 個人學習內容僅在使用者逐次檢視、於原欄位自行移除可識別敏感資料，並明確勾選當次同意後加入。
  - 第二階段與第三階段之同意核取方塊（consent checkbox）**各自獨立且不持久化儲存**；重新載入頁面時兩者均重置，切換校系目標時重置，確認刪除任何校系時重置。
  - 第三階段提示詞僅允許讀取該指定校系 UUID 於第二階段已記錄之備審資料，且僅在當次勾選同意後加入；**嚴禁跨校系讀取其他校系資料**。
- **不承諾招生資訊自動核實**：各大專院校與系所之當年度招生管道、資格限制、評量方式、指定繳交文件格式與二階筆面試規定，皆須由學生與輔導老師親自查核大專院校官方招生簡章與系所公告為準；AI 產出內容僅供參考，不得冒稱為正式考古題或官方規定。
