# 班級幹部小老師選取獎勵程式 升級修改指令

目標檔案（同資料夾）：`班級幹部小老師選取獎勵程式(codex優化版).html`
單一 HTML 檔：Tailwind（CDN）＋ SheetJS（CDN）＋ 一段原生 JavaScript。修改後行號會位移，請一律以**函式名稱或元素 id** 搜尋定位。

## 通則（每一批都適用）

1. **備份**：原始版已備份為 `班級幹部小老師選取獎勵程式(codex優化版)_備份_20261117.html`，不得修改備份檔。之後每批開始前，再把當時的目標檔複製成 `…_備份_<版本>_<日期>.html`（已存在就跳過）。
2. **只改目標檔**，維持單一 HTML，不新增程式檔。
3. **舊資料必須能開**：localStorage 鍵 `cc-class-assign`、IndexedDB 資料庫 `lssh-class-assign`、資料夾檔名 `幹部小老師資料.json` 都不可改名；新增欄位一律在 `normalizeData()` 補預設值，舊版 JSON 備份也要能匯入。
4. **不可刪除使用者資料**：覆蓋或移除名單／指派的動作都要先用 `askChoice()` 確認，並先 `makeSnapshot()` 留還原點。
5. **輸出一律跳脫**：姓名、學號、職務名稱寫進 `innerHTML` 一律用 `escapeHTML()`。
6. 介面文字用繁體中文；每批完成後抽出 `<script>` 執行 `node --check`，並在瀏覽器實測、確認主控台沒有錯誤。
7. 每批結束回報：已完成、未完成與原因、做過的檢查。沒驗證的事不要說成已驗證。

## 第 1 批：IndexedDB＋指定資料夾長期儲存（1.x → 2.0）✅ 已完成（2026-11-17）

做法比照「多班級成績管理系統」第 6、8 批：

- **儲存層**：IndexedDB `lssh-class-assign`（倉儲 `kv`：鍵 `state`、`folderHandle`、`folderKnown`；倉儲 `snapshots`）為主，localStorage `cc-class-assign` 為鏡像與後援。每份資料帶 `savedAt`、`rev`。
- **非同步啟動**：讀完兩邊、取 `savedAt` 較新的一份才繪製；讀取完成前任何儲存都不會執行。舊版只有 localStorage 的資料會自動搬進 IndexedDB 並讀回比對，原資料保留。
- **寫入安全**：0.3 秒合併、序列化寫入；分頁隱藏或關閉時立刻寫出；多分頁以 `rev` 檢查＋`BroadcastChannel` 提示。
- **自動還原點**：每天第一次儲存（保留 7 份），重設／匯入 JSON／載入資料夾前各留一份（保留 10 份），可還原或下載。
- **資料夾正本**（Chrome／Edge）：`幹部小老師資料.json`；每天第一次寫入前把前一版複製到 `幹部小老師資料_歷史/`（保留 14 份）；衝突時另存 `幹部小老師資料_衝突_<裝置>_<時間>.json`。首次連結三種情況、開啟時重新授權、別台電腦更新提示（回到頁面與每 60 秒檢查）、寫入失敗重試、中斷連結、更換資料夾都已實作。
- **介面**：頁首「💾 已儲存」「📁 已同步到資料夾」標籤（點擊前往設定區）、「立即儲存」按鈕取代原本的「儲存到本機／讀取本機」；頂端黃色提示列；「匯出 / 匯入」分頁新增「資料存放位置」「自動還原點」「兩台電腦共用資料怎麼設定？」。
- 附帶修正：名單／職務／下拉選單的姓名改為跳脫輸出；「重設全部」改為先留還原點且會正確存檔；移除檔尾殘留的 Cloudflare 驗證腳本（在本機開啟時只會載入失敗）。

測試方式：本機 http 伺服器＋內建瀏覽器，以 OPFS 子資料夾替身取代 `showDirectoryPicker`。**真實的資料夾選擇視窗、真實 Google 雲端硬碟同步、以 `file://` 開啟時的資料夾功能、IndexedDB 被停用時的後援模式都沒有實測。**

## 第 2 批：易用性與錯誤修正（2.0 → 2.1）✅ 已完成（2026-11-18）

完成摘要（備份：`…_備份_2.0_20261118.html`）：
- 分頁與類型按鈕改用 `setActive()` 成對切換樣式，加 `role="tab"`／`aria-selected`、`aria-pressed`；上次停留的分頁記在這台電腦（localStorage `cc-class-assign-tab`，不隨資料同步），重開自動回到該頁。
- 分配頁的「分配類型」下拉改為與任務清單相同的分段按鈕，兩頁共用 `state.ui.role`。
- 新增 `renderStats()` 統一計算；概況改為四格：學生總數、目前類型職務數、已指派（n / 總數）、**尚未有任何職務的學生**（含名單，最多列 12 人）。
- 刪除學生／職務改用 `askChoice()`（會說明此人目前擔任的職務），刪除後 toast 5 秒內可「復原」；清空名單、清空職務、清除指派先留還原點，也可復原。
- `toast()` 改為新訊息取代舊訊息並重新計時、可帶按鈕，加 `role="status"`。
- 隨機分配改用 Fisher–Yates `shuffle()`（6 萬次抽樣，六種順序各約 1/6）。
- 附帶修正：首次連結資料夾若寫入失敗，不再誤報「已在資料夾建立資料檔」。

以下為原始規格：

### 2.1 分頁與按鈕狀態
- 目前分頁的反白有錯：切換後選中的按鈕同時帶有 `bg-white` 與原本的 `bg-white/10`，由 CSS 順序決定誰贏，實測選中分頁變成淡底深字、幾乎看不出來（「學生名單」反而像被選中）。改用 `classList.toggle` 成對切換兩組樣式（選中＝白底深字，未選中＝半透明底白字），並加 `aria-selected`。「幹部任務／小老師任務」按鈕有同樣問題。
- `state.ui.tab` 有存但重新開啟時不會還原，請在啟動時切回上次的分頁。
- 任務清單的「幹部任務／小老師任務」切換與分配頁的「分配類型」下拉是兩套控制，常讓老師以為資料不見。改為兩頁共用同一個切換（分段按鈕），並同步 `state.ui.role`。

### 2.2 統計數字不一致
- `statTasks` 在 `renderTasksTable()` 顯示「全部職務數」，在 `refreshAssignUI()` 又顯示「目前類型職務數」，切換分頁時數字會跳。統一由一個 `renderStats()` 計算，並新增「尚未有職務的學生」人數（老師最常問的數字）。

### 2.3 確認與復原
- 單筆刪除學生／職務仍用 `confirm()`；改用 `askChoice()`，並提供「復原」：toast 顯示 5 秒「已刪除 王小明 〔復原〕」。
- 「清空名單」「清空職務」「清除此類全部指派」改為先留還原點。

### 2.4 Toast
- `toast()` 沒有清除前一個計時器，連按時訊息會提早消失；改為 `clearTimeout`，並加 `role="status"` 讓讀屏軟體讀出。

### 2.5 隨機
- `randomAssign()` 用 `sort(() => Math.random() - 0.5)` 打亂，分布不均；改為 Fisher–Yates。

## 第 3 批：分配頁重新設計（核心體驗）

- **左右兩欄**：左邊職務清單（含指派人），右邊「學生職務一覽」——每位學生一張小卡顯示已擔任的職務，0 項的學生用醒目色標出，一眼看出誰還沒有工作、誰兼太多。
- **合併欄位**：目前「指派給」「快速指定」兩欄重複顯示同一個人；改為一欄可搜尋的下拉（輸入座號或姓名即可篩選），旁邊放「隨機」「清除」小按鈕。
- **鎖定**：每個職務加 🔒，鎖定後「隨機分配未指派」與重抽都不會動到（例如班長已由選舉產生）。
- **抽籤動畫**：隨機時名字輪播約 1.5 秒後停下，投影到教室大螢幕時有儀式感；提供「關閉動畫」選項。
- **投影模式**：一鍵全螢幕大字顯示分配結果（職務｜姓名兩欄），適合班會公告。
- **拖曳指派**（可選）：把學生小卡拖到職務上。

## 第 4 批：學生名單頁

- 姓名、學號可直接點表格修改（目前只能刪除重加，會連帶清掉指派）。
- 搜尋框與依座號排序；顯示人數。
- 批次貼上支援 Tab 分隔（從 Excel 直接複製兩欄）與「座號 姓名」空白分隔，並在加入前預覽「將新增 N 位、略過重複 M 位」。
- 欄名統一：單筆新增寫「學號」、範本 CSV 寫「座號」，請統一為「座號／學號」。
- Excel 匯入三步驟（選檔→讀取班級清單→匯入）合併為：選檔後自動讀取，只剩「選班級→匯入」。

## 第 5 批：職務清單頁

- 職務可拖曳或上下箭頭調整順序（目前只能刪除重加）、可改名。
- 每個職務可設定「名額」（例如衛生股長 2 人）與「說明／職掌」，可連結校內《班級幹部職務執掌表》。
- 「生成常用職務」若已存在不會重複加入，但沒有提示；改為顯示「已新增 N 項，M 項已存在」。

## 第 6 批：「獎勵」功能（程式名稱有、目前沒有）

程式名稱是「選取**獎勵**程式」，但目前完全沒有獎勵相關功能。建議：
- 每位幹部／小老師可記點（＋1／−1、原因、日期），學期末匯出「服務表現」統計，可直接用於德行評語與學習歷程多元表現。
- 提供「服務證明」列印（班級、姓名、職務、期間、導師簽名欄）。
- 支援「上學期／下學期」兩個期別，保留歷史任職紀錄。

## 第 7 批：視覺、離線與無障礙

- **離線可用**：Tailwind Play CDN 與 SheetJS 都從網路載入，斷網或學校網路擋 CDN 時整頁沒有樣式、Excel 功能失效；Tailwind 官方也不建議 Play CDN 用於正式環境。改為把用到的 CSS 預先產生內嵌、SheetJS 內嵌（同成績系統第 7 批的做法）。
- **對比**：漸層背景上的 `text-white/60`、`text-white/70` 說明文字對比不足（低於 WCAG AA 4.5:1），改為 `/80` 以上，或改用淺色卡片底。
- **手機版面**：頁首按鈕與分配表在窄螢幕會擠成多行；表格改為卡片式排列。
- **鍵盤操作**：各表格動作按鈕加 `aria-label`（例如「刪除 王小明」）；對話框開啟時焦點鎖在對話框內。
- **列印 PDF**：加上班級名稱、學年學期、導師欄位；學生名單與分配結果分兩頁；可選「依座號」或「依職務」排序。
