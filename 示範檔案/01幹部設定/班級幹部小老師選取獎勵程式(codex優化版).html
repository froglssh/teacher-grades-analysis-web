📁 資料存放位置

兩台電腦共用資料怎麼設定？
  1. 兩台電腦都用 Chrome 或 Edge 開啟本程式（建議放在同一個 Google 雲端硬碟資料夾）。
  2. 兩台電腦各按一次「選擇資料存放資料夾」，選同一個雲端硬碟資料夾。瀏覽器只會顯示資料夾名稱，請在「位置備註」記下完整路徑。
  3. 原始資料就是該資料夾內的 幹部小老師資料.json；每天第一次寫入前會把前一版複製到 幹部小老師資料_歷史（保留 14 份）。
  4. 每次開啟可能要點一下頂端黃色提示列授權；Chrome 若出現「每次造訪都允許」可勾選。
  5. 換電腦前先確認標籤顯示「📁 已同步到資料夾」，並等雲端硬碟上傳完成；不要兩台同時開著修改。
  6. 若兩邊都改過，程式會詢問要用哪一份，另一份會存成 幹部小老師資料_衝突_裝置_時間.json 或本機還原點，不會直接遺失。
  7. 要搬移資料：在 Finder／檔案總管把 JSON 檔與「_歷史」資料夾搬到新位置，再按「更換資料夾」指向新位置。

🕒 自動還原點（存在這台電腦的瀏覽器）

每天第一次儲存時自動留一份（保留 7 天）；「重設全部」「匯入 JSON」「載入資料夾資料」前也會各留一份。

小提醒：資料只存在這台電腦的瀏覽器（及您選擇的資料夾）中，不會上傳到任何伺服器；仍建議定期下載 JSON 備份。
