學生打掃抽籤系統使用說明

臺北市立麗山高中林獻升老師製作。這份文件提供導師與班級幹部快速上手流程，協助完成學生名單匯入、內掃與外掃工作設定、抽籤分配、歷史紀錄保存與結果匯出。

一、快速開始

  1. 開啟線上版：https://froglssh.github.io/student-cleaning-lottery/。
  2. 在「班級資訊」輸入學年、學期與班級。
  3. 匯入 Excel 班級名單，或直接在學生名單欄位貼上姓名。
  4. 確認「打掃工作項目」的人數總需求是否與班級人數相符。
  5. 按下「抽籤安排」，檢查結果後可手動調整學生與細項內容。
  6. 按「紀錄目前結果」保存本次安排，再下載 Excel、圖片或 PDF。
建議流程是先確認人數，再抽籤，再紀錄。若工作需求人數與學生人數不相符，系統仍可抽籤，但可能會有人重複或有人沒有工作。

二、設定班級資訊與學生名單

班級資訊

請在左側「班級資訊」輸入學年、學期與班級，例如 114、上學期、307。這些資訊會出現在工作分配表標題與下載檔名中。

使用 Excel 匯入名單

  1. 按「選擇 Excel / CSV 檔案」。
  2. 若檔案有多個班級分頁，請在「班級分頁」選擇要使用的班級。
  3. 姓名欄位可使用自動偵測；若偵測錯誤，請手動選擇姓名欄。
  4. 按「匯入所選班級名單」。

系統會盡量偵測「姓名、學生、座號、學號」等欄位。若名單無法匯入，請確認 Excel 第一列附近是否有清楚的欄位標題。

手動輸入名單

可在學生名單欄位每行輸入一位學生。支援只輸入姓名，也支援 01 王小明 這種座號加姓名格式。完成後按「載入名單」。

三、設定內掃與外掃工作

工作項目分為「內掃區域」與「外掃區域」。系統會在標題旁顯示各區需求人數，並在「打掃工作項目」標題旁顯示總需求與班級人數差額。

區域 預設項目 使用建議
內掃區域 內掃督導、黑板講桌、掃地、拖地、窗戶窗台、教室走廊、資源回收、倒垃圾、支援 依班級實際需求調整每項人數。若要新增內掃任務，按「新增內掃工作」。
外掃區域 外掃督導 每班外掃區不同，請按「新增外掃工作」自行加入項目，例如花圃、穿堂、樓梯、川堂等。
新增工作時，工作名稱會先保持空白，請老師自行輸入名稱與人數。細項內容可先空白，抽籤後再補充給學生看的具體說明。

四、抽籤安排與手動調整

抽籤前檢查

請先看「打掃工作項目」旁的人數提示。例如「總需求 29 人 / 班級 29 人（人數相符）」代表每位學生剛好可以分到一個工作。

執行抽籤

按「抽籤安排」後，右側會出現完整工作分配表。表格會一次顯示所有工作，不使用內部垂直捲動，方便老師一次檢查全班分配。

手動調整

  • 「細項內容」可補充更明確的工作說明，例如「第二排」「窗台左側」「回收籃整理」。
  • 「手動調整」可重新指定該工作負責學生。
  • 下載圖片或 PDF 時，手動調整欄位不會顯示，輸出結果會更乾淨。

五、紀錄結果與回復歷史

每次抽籤後，可在「本次結果名稱」輸入名稱，例如 第一次、第二次、期中後，再按「紀錄目前結果」。

  • 歷史紀錄會保留在網頁本機瀏覽器中，可作為下次安排參考。
  • 若要查看以前結果，請在「歷史資料」選取紀錄，再按「回復選取紀錄」。
  • 若不需要舊資料，可刪除單筆紀錄或清除所有紀錄。
歷史紀錄保存在目前使用的瀏覽器中。若換電腦或換瀏覽器，請先下載 JSON 備份，再於新環境匯入。

六、下載、備份與還原

功能 用途 提醒
下載 Excel 產生可編修的打掃分配表。 適合交給行政、班級幹部或另行列印。
下載圖片 產生 PNG 圖片。 適合貼到班級群組、簡報或公告。

七、常見問題

為什麼人數顯示多幾人或少幾人？

這代表工作項目的人次總需求與學生人數不一致。請調整各工作項目的「人次」欄位，直到總需求與班級人數相符。

外掃區域為什麼只有外掃督導？

因為每個班級的外掃區域通常不同，所以系統不預設外掃細項。請老師依學校分配區域自行新增。

下載圖片或 PDF 時，為什麼沒有手動調整欄？

手動調整欄只供老師在網頁中修改分配，正式輸出時會自動隱藏，讓公告表格更簡潔。

資料會不會傳到網路？

本程式是前端單頁工具，學生名單、工作設定與歷史紀錄主要保存在使用者自己的瀏覽器中。若需要跨裝置使用，請下載 JSON 備份檔自行保存。
