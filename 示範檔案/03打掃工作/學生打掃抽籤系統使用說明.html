學生打掃抽籤系統使用說明v3.0

臺北市立麗山高中林獻升老師製作。依「班級與名單 → 打掃工作 → 抽籤分配 → 結果與輸出 → 紀錄與資料」五個步驟，完成全班內掃、外掃工作分配，並長期保存每次的紀錄。

快速開始（第一次使用約 5 分鐘）

  1. 班級與名單填學年、學期、班級，貼上名單或匯入 Excel。
  2. 打掃工作設定內掃、外掃工作與人次，讓「人數對照」顯示相符。
  3. 抽籤分配按「隨機填滿空位」，再點選或拖曳微調。
  4. 結果與輸出投影公告，或列印、下載 PNG／PDF／Excel。
  5. 紀錄與資料選一個雲端硬碟資料夾，讓資料長期保存。

頁面上方的五個步驟標籤會顯示目前狀態：綠色代表完成，橘色代表需要處理（例如人數不符）。

每次輪替時，只要回到步驟 3 按 ＋ 開始新一輪 → 🎲 隨機填滿空位 → ✓ 完成並存入紀錄 即可。名單與工作設定都會沿用。

1班級與學生名單

班級資訊

填寫學年（例如 115）、學期、班級（例如 201）與導師姓名。這些資訊會出現在分配表標題、列印頁與下載檔名。導師姓名為選填，僅用於列印。

方法一：貼上或輸入名單

  1. 在「建立名單」選 貼上／輸入。
  2. 每行一位，可寫 01 王小明 或只寫姓名；也可以直接從 Excel 複製「座號、姓名」兩欄貼上。
  3. 按 套用為班級名單。重複的姓名會自動略過。

方法二：匯入 Excel／CSV

  1. 選 Excel 匯入，點選或把檔案拖進虛線框。
  2. 有多個班級分頁時，在「班級分頁」選要用的班級。
  3. 下方會預覽「偵測到 N 位學生」；若姓名抓錯，請改選「姓名欄位」。
  4. 按 匯入這個分頁的學生。

班級名冊

  • 右側名冊可用座號或姓名搜尋；每位學生下方的小字是目前分配到的工作。
  • 按學生右側 × 可單獨移除（6 秒內可按「復原」）。
  • 重新套用名單時，系統會先詢問並留一份還原點；同名學生的分配會保留，不在新名單上的學生分配會取消。

2打掃工作與人次

工作分成 🏫 內掃區域 與 🌳 外掃區域 兩張表，每項工作可設定：

欄位說明
▲ ▼調整工作順序（分配表、輸出都依此順序）。
工作名稱例如掃地、拖地、樓梯間。人次 2 以上會自動編成「掃地 1、掃地 2…」。
人次 − ＋這項工作需要幾位學生（1–30）。
細項說明選填，會印在分配表上，例如「第一、二排」「回收籃整理」。
🗑刪除這項工作（可復原）。

人數對照

右側「人數對照」會即時比較「班級學生」與「工作人次」，並直接給建議：

  • ✓ 人數相符：每位學生剛好一份工作。
  • 工作人次比學生多：抽籤後會有位置空著，建議減少人次。
  • 學生比工作人次多：會有學生沒有工作，建議增加人次（例如「支援」）。

快速建立

  • 載入常見工作範本：內掃督導、黑板講桌、掃地、拖地、窗戶窗台、教室走廊、資源回收、倒垃圾、支援、外掃督導。
  • 批次貼上：每行一項，格式 工作名稱, 人次, 細項；開頭加 外掃, 才會放進外掃區，例如 外掃, 樓梯間, 2, 掃地拖地。
已經抽好籤之後再修改工作名稱、細項或人次，已分配的學生會留在原位置；只有被刪除或減少的位置上的學生會回到「未分配」。

3抽籤分配

進入此頁會自動建立本次分配表。頁面上方是操作列，下方左側是學生清單，右側是每個工作位置的卡片。

操作列

項目說明
本次名稱例如「第 3 次（11/24 起）」，會顯示在分配表與紀錄中。
平均分配參考歷史紀錄，打掃次數較少的學生優先分到工作（學生比位置多時特別有用）。
避免重複同一工作上一次做過某工作的學生，這次盡量不再抽到同一工作；其次參考累計次數。
🎲 隨機填滿空位只把空位補滿，已分配與鎖定的位置不動。
↻ 重抽未鎖定除了鎖定的位置，全部重新抽。
清空未鎖定把未鎖定位置上的學生全部移回未分配。

＋ 開始新一輪建立新的空白分配表；若目前結果尚未存入紀錄，會先詢問。鎖定的位置會帶到新一輪。

範例：一般位置、鎖定的位置（黃色）、外掃空位（綠色左邊線）。

  • 🎲 隨機抽／重抽：只為這一個位置從未分配學生中抽一位。
  • 🔓 鎖定：鎖定後變成「🔒 已鎖定」，重抽、清空、開始新一輪都不會變動它（適合已指定的督導或特殊需求學生）。
  • ✕ 取消：把這位學生移回未分配。
  • 卡片下方「細項」可填只屬於這個位置的說明，例如「掃地 1：前半間」。

手動指定學生（三種方式）

  1. 點選：在左側點一位學生（變成綠框），再點任一工作卡片即可放入。
  2. 交換：直接點卡片上的學生，再點另一張卡片，兩人會互換位置。
  3. 拖曳：把學生拖到卡片上；把卡片上的學生拖回左側清單＝取消分配。

左側清單可切換 未分配／全部。按 Esc 可取消目前的選取。

所有分配動作下方都會出現提示列，6 秒內按 復原 就能回到上一步。

4結果與輸出

右側就是實際列印、匯出的樣子。左側可選擇：

  • 排列方式：依工作（分內掃、外掃兩段）或 依座號（方便學生找自己的工作，未分配者也會列出）。
  • 顯示細項說明、加入簽名欄（衛生股長、導師）。
按鈕用途
📺 投影模式全螢幕大字顯示全班分配，適合班會或教室螢幕公告；按 Esc 關閉。
🖨️ 列印只印分配表（A4 直式）。
🖼️ 下載圖片 PNG貼到班級群組、Classroom 公告。
📄 下載 PDFA4 自動分頁，不會把表格列切斷。
📊 下載 Excel含「依工作」「依座號」兩個工作表，可再編修。

若這份結果還沒存入紀錄，左側會提醒並提供 ✓ 存入紀錄 按鈕。

5紀錄與資料

歷次分配紀錄

  • 載入：把舊紀錄帶回步驟 3，可再修改後重新存入（會更新該筆紀錄）。
  • 改名、刪除（可復原）；清除全部紀錄 前會留一份還原點。
  • 標示「目前分配」的那一筆，就是步驟 3 正在編輯的結果。

學生打掃歷程

統計每位學生的打掃次數、最近一次的工作與做過的工作。黃色 表示同一工作做過 2 次以上；「較少」標記次數最少的學生。這也是「平均分配」「避免重複」的依據，所以每次分配完記得存入紀錄。

💾 資料保存與備份

資料不會上傳到網路，全部保存在您自己的電腦或您選擇的資料夾。頁首的狀態標籤可點擊前往設定：

  • 💾 已儲存 21:05：每次修改都會自動存到這台電腦的瀏覽器（IndexedDB）。
  • 📁 已同步到資料夾：已連結資料夾，修改會自動寫入資料夾。
  • 立即儲存：馬上寫入（離開前想確保存檔時使用）。

建議：選擇長期存放的資料夾（Chrome／Edge 電腦版）

  1. 到「紀錄與資料」→「資料存放位置」，按 📁 選擇資料存放資料夾。
  2. 建議選 Google 雲端硬碟中的一個資料夾，程式會建立 打掃抽籤資料.json。
  3. 之後每次開啟會自動連回；若瀏覽器要求重新授權，頁面上方會出現黃色提示列，按 連接資料夾 即可。
  4. 每天第一次寫入前，前一版會備份到 打掃抽籤資料_歷史 資料夾（保留 14 份）。

學校、家裡兩台電腦共用

  1. 兩台電腦都安裝 Google 雲端硬碟電腦版，並用 Chrome 或 Edge 開啟程式。
  2. 兩台都選同一個資料夾。第二台選擇時若兩邊都有資料，程式會讓您選擇要用哪一份，沒選的那份會另存，不會遺失。
  3. 另一台電腦更新後，回到頁面時會出現「載入最新資料」提示。

可在「這台電腦的名稱」填入「學校電腦」「家裡電腦」，方便辨識是哪台存的資料。

自動還原點與 JSON 備份

  • 自動還原點：每天 1 份（保留 7 天），以及取代名單、載入範本、清空、匯入、重設前各 1 份（保留 10 份），可「還原」或「下載」。
  • 下載 JSON 備份／匯入 JSON 備份：完整備份班級資訊、名單、工作、目前分配與全部紀錄；舊版（v2）的備份也能匯入。
若只存在瀏覽器、沒有連結資料夾，清除瀏覽器資料或換電腦就看不到資料。Safari、Firefox 不支援選擇資料夾，請定期下載 JSON 備份。

常見問題

舊版的資料還在嗎？

在。第一次開啟 v3 時，會自動把舊版存在瀏覽器的資料（名單、工作、目前結果、歷史紀錄）搬過來，原資料也保留。

改了工作設定，分配表出現黃色提示？

代表目前分配表的工作位置與步驟 2 的設定不同（常見於載入舊紀錄後）。按 依目前工作設定更新，已分配的學生會盡量保留在原位置。

按了「隨機填滿空位」還有空位？

表示所有學生都已有工作，工作人次比學生多。可回步驟 2 減少人次，或保留空位。

為什麼「平均分配」好像沒有作用？

這兩個規則都依據「歷次分配紀錄」。若之前沒有按「完成並存入紀錄」，系統就沒有歷史可參考。

按錯了怎麼辦？

大部分操作 6 秒內可按提示列的「復原」；較大的變動（取代名單、清空、匯入、重設）前會自動留還原點，可在「紀錄與資料」→「自動還原點」還原。

在「班級經營工作站」開啟時有什麼不同？

學生名單、班級與學年學期由工作站的「共用名冊」自動帶入，不能在本程式修改；資料存在工作站的共用資料庫，備份請使用工作站的「資料中心」。
