2026-11-14 全面改版重點

  • 全班名單模式：貼上或匯入名單後，左側顯示全班進度，一位接一位完成；同一台電腦可保存多個班級學期。
  • 評語依知識庫規範產生：單用名不帶姓、男「你」女「妳」、五段模組、待改進項目一律寫成成長建議，並依篇幅自動控制字數。
  • 即時八大品質檢核與四大紅線：懲處紀錄、家庭隱私、身心健康、人格宣判字眼會立即標紅。
  • 全班匯入與匯出：自評表、Google 表單、社團名單、前學期評語可一次匯入；全班 Excel 一列一位、可依座號複製整欄到校務系統。
  • AI 潤飾去識別化：送出前把姓名換成「○○」，不送座號、學號與學生自評原文。
  • 舊版相容：舊版草稿可在「匯入 → 匯入舊版草稿」轉入；舊版程式保留在 OLD/ 資料夾。

一、三分鐘快速上手

  1. 開啟線上版〈導師評語生成系統（線上版）〉或本機〈導師評語生成系統（codex優化版）.html〉。建議使用電腦 Chrome、Edge 或 Safari；手機、平板亦可流暢操作。
  2. 第一次使用可按左上方「先試用範例」，一鍵建立 3 位虛擬學生體驗完整撰寫流程。
  3. 正式使用時，按「設定」填寫班級、學年度與年級學期，再建立名單（見第二節）。
  4. 每位學生依三個步驟點選，右側評語即時產生；確認後按「標記完成並前往下一位」。
  5. 全班完成後按「匯出」，下載 Excel 或整欄複製貼入校務系統。

二、建立班級名單

方法 1：貼上名單

從校務系統或 Excel 複製「座號、姓名、性別」三欄，按左下「貼上名單」貼上即可。欄位可用 Tab、逗號或空白分隔，學號可有可無。

01　林郁婷　女
02　陳柏翰　男
03　王思妤　女

方法 2：匯入 Excel／CSV／Word

按上方「匯入」選擇檔案，系統會自動判斷欄位並列出對應表，您可逐欄調整「匯入到」的位置後再套用。依「座號＋姓名」比對名單，名單中沒有的學生可自動新增。

可匯入的檔案系統會帶入
全班基本資料座號、姓名、性別（手機、住址、生日、身分證、家長資料會自動鎖定，絕不上傳匯入）
學生德行自評表（Excel／CSV）學校服務、社團、學業、生活常規、社會服務、活動表演、科學展覽、校內外其他表現
Google 表單自評回覆個性、向學、進取等描述放入「學生自述」；若填的是三位數代碼則直接選取代碼。時間戳記與電子郵件會鎖定不匯入
單一學生 Word 自評表（.docx）自動解析並套用到對應座號學生
社團名單社團名稱與職稱
前學期評語放入「上學期評語（參考）」，撰寫時可對照、避免重複
其他系統匯出的單一學生直式資料表以「欄位—內容」方式辨識，選擇要套用的學生
匯入後若結果不對，可在提示訊息按「復原」回到匯入前狀態。研習練習檔在〈00學生資料／匯入練習_虛擬班級資料〉。

三、三步驟撰寫每位學生

畫面上方是學生基本資料（座號、姓名、性別、語氣）。系統會自動取「名」作為評語稱呼，例如「林郁婷」稱「郁婷」、「歐陽娜娜」稱「娜娜」；需要時可在「評語稱呼」覆寫。

步驟 1：印象與代碼

  • 評語代碼：可直接搜尋（如輸入「熱心」或「302」），或點分類瀏覽。建議選 1–3 個，第一個會寫在開頭，可用 ↑ 調整順序。
  • 常用組合：品學兼優型、服務奉獻型、才華活力型、溫和人緣型、穩健踏實型、勉勵精進型，一鍵帶入。
  • 待改進代碼（灰色）不會原文寫入評語，會自動改寫成具體正向的成長建議。
  • 一件具體小事：最能讓評語有溫度，會接在開頭句後。
  • 個性與人際：點「佳」寫成優點，點「再加強」寫成建議。

步驟 2：學習與生活

  • 學業概況（名列前茅／表現優良／表現穩定／持續進步／仍在摸索）、優勢學科、希望加強的學科。
  • 出缺勤（全勤會寫入「這學期全勤，準時到校上課」）與生活常規。
  • 希望再加強的地方：最多 2 項，系統以正向語氣寫進結尾。待加強項目若超過 2 項，右側會提醒哪些沒有寫入。

步驟 3：職務與表現

  • 擔任職務：點選班級幹部、科目小老師或自治社團職務，系統自動帶入工作內容描述（例如衛生股長「督導打掃工作與資源回收」），可調整表現：認真負責、具領導力、默默付出、主動積極、可再主動。
  • 競賽、活動與成果：選類別與層級（校內、區域、縣市、全國、國際），有名次再填成果。只寫真實發生的事。
  • 學生自評資料：僅供參考，按「轉為活動」才會寫入評語與特殊表現。
  • 導師補充與想對學生說的話：分別接在結尾之前與最後一句。

四、評語模組、檢核與特殊表現

評語如何組成

依麗山高中德行評語知識庫的五段模組：德性品格 → 學業表現 → 職務服務 → 特殊事蹟 → 期許結尾。沒有資料的段落會略過，不會自行補寫虛構情節。

篇幅設定建議字數段落結構說明
自動150–350依資料多寡決定，超過上限時自動省略次要細節
精簡150–200品格＋學業＋期許
標準200–280再加入職務服務
完整280–350五段全部展開
高三下三年總評300–400在「設定」選高三下，改以「○○同學高中三年…」客觀綜述，結尾給大學發展建議

結尾開頭會依年級學期調整，例如高一上「新的一年」、高二下「邁向高三的關鍵階段」、高三上「面對即將到來的升學挑戰」。

即時八大品質檢核

檢核項目檢查標準與處理方式
稱謂以名字開頭、不帶姓、不出現生硬的「該生」
代詞男生「你」、女生「妳」全篇一致；三年總評用他／她
具體事例必須有具體小事、職務、活動或補充觀察，避免空泛成語堆砌
事實不捏造評語中的名次、獎項字眼必須出現在輸入資料中（特別用於防堵 AI 幻覺）
零批判字眼自動偵測「懶散、總是遲到、沉迷、很爛」等負向標籤，並提供正向改寫建議
結尾期許最後一句必須具備正向期許或勉勵
評語代碼已選 1–3 個
字數控制精準落在所選篇幅的字數安全區間內
四大紅線（絕不妥協）：懲處紀錄、家庭經濟與家庭狀況、身心健康與醫療隱私、人格宣判字眼。出現時會以紅框標示，且無法標記完成，必須先修改。

特殊優良表現

由職務、競賽活動、社團、服務學習與學生自評自動整理，可切換「段落」或「條列」。可取消「納入學生自評」。

本學期擔任學藝股長，工作認真負責且表現良好。參加臺北市科展，獲得佳作。本學期全勤。

五、全班總覽與批次作業

上方「全班總覽」列出每位學生的狀態、代碼、字數、檢核分數與評語摘要，點一列即可開啟該生。

  • 全班依勾選重新生成：套用最新規則，手動修改過與已完成的學生不受影響。
  • 全班 AI 潤飾：逐位潤飾尚未潤飾、尚未完成的學生，可隨時停止。

六、匯出與複製

匯出方式功能說明

列印／存成 PDF列印目前學生或全班，在列印視窗選「另存為 PDF」

七、班級學期管理

  • 上方選單可切換班級學期；選「＋ 新增班級學期」可建立下一學期。
  • 新學期可選「沿用目前名單」：座號、姓名、性別會帶過去，上學期的評語與特殊表現保留為參考。
  • 「設定」中可刪除班級學期（刪除前建議先下載 JSON 備份）。

八、AI 潤飾（選用功能）

系統內建的評語生成完全在瀏覽器中完成，不需要 AI。若要進一步修飾文字：

  1. 按「設定」，選擇 Google Gemini 或 ChatGPT／OpenAI。
  2. 按「取得 API 金鑰」申請並貼上金鑰。公用電腦請勿勾選「記住金鑰」，關閉分頁後即失效。
  3. 可按「預覽送出內容」查看實際送出的文字。
  4. 回到學生畫面按「✨ 潤飾」。潤飾後仍會經過八大檢核，特別是「事實不捏造」。
隱私保護去識別化：送出前，學生姓名與名字會被替換為「○○」，回傳後再換回；座號、學號、學生自評原文絕對不會送出。自訂模型欄位留空時，系統會自動選擇可用模型。

九、資料與隱私安全

  • 所有資料只存在這台電腦的瀏覽器（localStorage），絕不會上傳到任何外部伺服器。
  • 換電腦、清除瀏覽紀錄或使用無痕視窗前，請先「匯出 → 備份」。
  • 同時開兩個分頁編輯時，系統會暫停其中一頁的儲存，避免互相覆蓋，請重新載入。
  • 備份 JSON 與 Excel 包含學生個人資料，請依學校個資與資安規範妥善保管。

十、常見問題解答

評語太短？

系統不會自行編造內容。請補一件具體小事、職務或活動，或在「導師補充」寫一句觀察。

我手動改過的評語會不會被覆蓋？

不會。手動修改後只有按「依勾選重新生成」才會覆蓋，且可用「復原上一版」找回。

一位學生同時有很多待加強的地方？

評語只寫最多 2 項，避免整段變成缺點清單。右側會提示沒有寫入的項目，可在步驟 2 調整要寫哪兩項。

舊版的草稿還在嗎？

在。按「匯入」→「匯入舊版草稿」即可轉入目前班級；舊版資料仍保留在瀏覽器中。

鍵盤快捷鍵

Alt＋↑／↓ 切換上一位／下一位學生；Esc 關閉視窗或名單展開。
