班費收支記帳程式使用說明v3.0

臺北市立麗山高中林獻升老師製作。每一筆班費收入、支出隨手記下，附上收據照片，隨時看到結餘；學期末一鍵產生收支報告表（列印、PDF、Excel），資料可長期存在雲端硬碟資料夾。

▶ 開啟程式 💾 資料怎麼保存？

快速開始（第一次使用約 3 分鐘）

  1. 資料與設定填學年、學期、班級、導師；若手上已有班費，填「期初結餘」。
  2. 選存放資料夾同一頁選一個 Google 雲端硬碟資料夾，資料就能長期保存。
  3. 記一筆每次收錢或花錢：選收入／支出、填項目與金額，按 Enter。
  4. 報表輸出期中或學期末印出報告表，或下載 PDF、Excel 公布與核銷。
v3.0 只記「班費的收入與支出」，不再逐一登記每位學生的繳費。收班費時，收齊後記一筆「11 月班費收繳」即可（備註可寫「38 人 × 200 元」）。

累計收入$7,600
累計支出$2,380
本月（11 月）+$7,600 −$480
目前結餘（班費現金）$6,720

示意圖。目前結餘＝期初結餘＋累計收入－累計支出，應該等於手上的班費現金。

  • 點「累計收入」或「累計支出」，會直接跳到明細並只列出收入或支出。
  • 結餘變成負數時，摘要卡會變紅並提醒：通常是有收入還沒記。
  • 手機上只顯示結餘、收入、支出三張卡，畫面比較精簡。

1記一筆

＋ 收入－ 支出
  1. 先選 ＋ 收入 或 － 支出（送出按鈕的顏色會跟著變綠或紅，避免記反）。
  2. 日期預設今天，可按 昨天 或自行選擇。
  3. 金額可直接打 1200、1,200、$350、350元，全形數字也可以。
  4. 項目寫清楚用途，例如「購買垃圾袋、抹布」「11 月班費收繳」。輸入時會出現以前用過的項目可直接選。
  5. 類別會依項目自動選好（例如「垃圾袋」→清潔用品），也可以自己點選；按 ＋ 新類別 可新增。
  6. 經手人、備註（發票號碼、店家）為選填；經手人預設帶入設定中的總務股長。
  7. 按 💾 記下這筆收入／支出 或直接按 Enter。
文具用品清潔用品影印印刷活動費用餐飲點心班級布置禮品獎品其他支出

預設支出類別（可在「資料與設定」修改）。

附上收據／單據照片

  • 點虛線框選照片、把照片拖進框內，或複製截圖後直接按 Ctrl／⌘＋V 貼上。
  • 照片會自動縮小壓縮（每張約 100–200 KB），不必擔心空間。iPhone 的 HEIC 照片若無法讀取，請先轉成 JPG。
  • 明細表中點縮圖可放大查看、下載。

省時小技巧

  • 右側常用項目：點一下就帶入項目、類別和上次的金額，只要確認金額再按 Enter。
  • 勾選 下一筆沿用同一天：一次補記同一天的多張收據時很方便。
  • 右側最近記錄可直接修改或刪除剛記的帳。

防呆提醒

  • 沒填項目或金額格式不對，欄位下方會直接說明哪裡要補。
  • 同一天已有相同項目、相同金額時，會詢問是否重複記帳。
  • 金額 5 萬元以上會請您再確認（避免多打一個 0）。

2收支明細

所有收入與支出合在一張表，依日期排列。「結餘」欄是記完該筆之後的班費餘額，方便和實際現金對帳。

功能說明
🔍 搜尋可搜尋項目、備註、經手人、類別、日期或金額。
篩選全部／收入／支出、月份、類別；表格下方即時顯示篩選結果的收入、支出與淨額小計。
↓ 新到舊切換排序方向。
✏️ 修改資料帶回「記一筆」，上方出現黃色「正在修改」提示；按 儲存修改 才會更新，按 取消修改 或 Esc 不會變動原紀錄。
⧉ 複製以這筆為範本新增一筆（日期改成今天），適合每月固定的支出。
🗑 刪除刪除後 7 秒內可按畫面下方的 復原。

3報表輸出

  1. 報表期間：全部（整本帳）、指定月份，或自訂起訖日期。指定期間時，「期初結餘」會自動算到該期間開始前。
  2. 報表內容：可選擇是否顯示經手人、備註、類別小計、簽名欄。
  3. 右側就是實際輸出的「班費收支報告表」：期初結餘、本期收入、本期支出、期末結餘，逐筆明細與每筆後的結餘。
輸出用途
🖨️ 列印報告表只印報告表本身（不會印到按鈕與選單），可在列印視窗選「另存為 PDF」。
📄 下載 PDFA4 直式，依表格列自動分頁、不會把一列切成兩半。勾選「PDF 附上單據相片」時，後面會附上每筆的收據照片（每頁 2 張，含日期、項目、金額說明），方便交給學校核銷。
📊 下載 Excel四個工作表：收支明細、月份統計（含月底結餘）、類別統計、基本資料。
要在班上公布或貼在聯絡簿時，可取消「備註」「經手人」，只留下日期、項目與金額。報表上方的「收支概況」會顯示每月收支長條與支出類別比例，班會報告時很好用。

4資料與設定

班級資訊

學年度、學期、班級、導師、總務股長會出現在頁首與報表上。期初結餘是開始記帳時手上已有的班費（例如上學期轉入），可搭配期初日期。

類別設定

收入、支出類別每行一個。修改類別不會更動已記的帳；已用過但被移除的類別仍會出現在篩選中。按 恢復預設類別 可還原。

學期結算・開新帳本

  1. 學期末先到「報表輸出」印出或下載本學期的報告表留存。
  2. 按 📅 結算並開新帳本…，建議選 下載備份並開新帳本。
  3. 明細會清空，目前結餘自動成為新帳本的期初結餘，期初日期設為今天；班級資訊與類別保留，記得把「學期」改成下學期。
  4. 舊帳本會存成還原點，必要時可在「自動還原點」還原或下載。

清除全部資料

清空所有收支、班級資訊與類別設定，清除前會自動留一份還原點。

💾 資料保存與備份

資料不會上傳到網路，全部保存在您自己的電腦或您選擇的資料夾。頁首的狀態標籤可點擊前往設定：

  • 💾 已儲存 21:05：每次修改都會自動存到這台電腦的瀏覽器（IndexedDB）。
  • 📁 已同步到資料夾：已連結資料夾，修改會自動寫入資料夾。
  • 立即儲存（或 Ctrl／⌘＋S）：馬上寫入，離開前想確保存檔時使用。

建議：選擇長期存放的資料夾（Chrome／Edge 電腦版）

  1. 到「資料與設定」→「資料存放位置」，按 📁 選擇資料存放資料夾。
  2. 建議選 Google 雲端硬碟中的一個資料夾（例如「班級經營／班費」）。程式會建立：
    • 班費收支資料.json：帳本本身。
    • 班費收支_單據相片：每張收據一個 .jpg 檔。
    • 班費收支資料_歷史：每天第一次寫入前備份前一版（保留 14 份）。
  3. 之後每次開啟會自動連回；若瀏覽器要求重新授權，頁面上方會出現黃色提示列，按 連接資料夾 即可。

學校、家裡兩台電腦共用

  1. 兩台電腦都安裝 Google 雲端硬碟電腦版，並用 Chrome 或 Edge 開啟程式。
  2. 兩台都選同一個資料夾。第二台選擇時若兩邊都有資料，程式會讓您選擇要用哪一份，沒選的那份會另存，不會遺失。
  3. 另一台電腦更新後，回到頁面時會出現「載入最新資料」提示；收據照片也會從資料夾自動讀取。

可在「這台電腦的名稱」填入「學校電腦」「家裡電腦」，方便辨識是哪台存的資料。

自動還原點與 JSON 備份

  • 自動還原點：每天 1 份（保留 7 天），以及匯入、還原、學期結算、清除前各 1 份（保留 10 份），可「還原」或「下載」。
  • ⬇ 下載完整備份：一個 JSON 檔包含班級資訊、所有收支與收據照片，可存到隨身碟或寄給自己。
  • ⬆ 從備份檔還原：還原前會顯示兩邊的筆數與結餘讓您確認，並先留還原點。
若只存在瀏覽器、沒有連結資料夾，清除瀏覽器資料或換電腦就看不到資料。Safari、Firefox 不支援選擇資料夾，請定期下載 JSON 備份。

常見問題

舊版（v2）的資料還在嗎？

在。第一次開啟 v3 時，會自動把舊版的自動存檔轉過來，並跳出說明；舊版資料仍留在瀏覽器中沒有刪除。舊版用「檔案名稱」另存的檔案、舊版匯出的 JSON，可在「資料與設定」→「備份與還原」匯入。

舊版「每位學生的繳費紀錄」到哪裡去了？

新版不再逐人登記。轉換時，舊版的繳費紀錄會依日期合併成「班費收繳（N 筆）」收入；舊版已經和收入「對帳」過的繳費不會重複計算，所以結餘和舊版完全相同。若需要每位學生的繳費明細，請保留舊版匯出的檔案。

那要怎麼知道誰還沒繳班費？

建議由總務股長用紙本或試算表打勾，收齊後在本程式記一筆收入即可；本程式專注在「錢從哪來、花到哪去、還剩多少」。

結餘和手上的現金對不起來？

到「收支明細」看每一列的結餘，從最近一次確定正確的日期往後檢查；常見原因是漏記收入、同一筆記了兩次，或收入／支出選反。也請確認「期初結餘」是否正確。

按錯了怎麼辦？

新增、修改、刪除後 7 秒內可按畫面下方的「復原」；較大的變動（匯入、還原、學期結算、清除）前會自動留還原點，可在「資料與設定」→「自動還原點」還原。

PDF、Excel 按了沒反應？

這兩個功能需要網路載入函式庫。請確認網路連線後重新整理頁面；暫時離線時可先用「列印報告表」再選「另存為 PDF」。

快速鍵

Enter 送出這筆；Esc 取消修改；Alt＋1～4 切換分頁；Ctrl／⌘＋S 立即儲存。
