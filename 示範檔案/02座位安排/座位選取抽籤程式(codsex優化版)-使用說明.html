教室座位抽籤程式 2.0 使用說明

輸入名單、隨機或手動排座位、固定特殊需求學生、標上幹部職務、保存每次安排，並把資料長期存放在指定資料夾。

一、2.0 有什麼不同？

項目舊版（1.x）2.0
儲存要按「儲存」才會存；重新整理就可能遺失每次修改自動儲存（IndexedDB），可再指定雲端硬碟資料夾長期保存
班級方案名稱＋儲存／讀取／刪除頁首「班級方案」下拉選單直接切換，可新增、複製、刪除
模式預覽／手動／編輯三種只有「🪑 排座位」與「🧱 編輯格局」兩種
調座位只能用滑鼠拖曳點兩個座位即可交換，觸控螢幕、平板也能用；仍可拖曳
改排數會清空已排好的座位保留已排學生，超出範圍的才回到「未安排」
其他—🔒 固定座位、↶ 復原、自動還原點、🖥 投影全螢幕
舊資料會自動搬過來：在同一台電腦、同一個瀏覽器第一次開啟 2.0 時，舊版存過的所有方案（含安排紀錄、學生標籤）會自動轉成班級方案，舊資料仍保留不刪。舊版下載的「方案 JSON」也可以在「⑤ 資料 → 匯入 JSON」讀入。

二、畫面配置

  • 頁首：班級方案下拉選單與「＋ 新增」、儲存狀態（💾 已儲存）、資料夾狀態（📁 已同步到資料夾）、「立即儲存」。點儲存或資料夾標籤會跳到資料設定。
  • 左側五個分頁：① 名單、② 格局、③ 標籤、④ 紀錄、⑤ 資料。程式會記住上次停留的分頁。
  • 右側工作區：工具列 → 統計（座位、可用、名單、已安排、未安排、固定）→ 操作提示 → 座位表 → 未安排的學生。

三、快速上手（五步驟）

  1. 「① 名單」輸入班級名稱、教室，貼上學生名單後按「套用名單」。
  2. 「② 格局」設定前後排數與左右行數，按「套用格局」。
  3. 工具列切到「🧱 編輯格局」，點沒有桌椅的位置設為空位；完成後切回「🪑 排座位」。
  4. 按「🎲 隨機分配」，再用點選或拖曳微調。
  5. 「④ 紀錄」輸入「第一次座位」按「保存」；需要時按「⬇ 下載」輸出 PNG。

四、① 名單：班級方案與學生名單

班級方案

一個班級方案包含：班級、教室、座位格局、學生名單、學生標籤與安排紀錄。所有方案都自動儲存，不必再按「儲存」。

  • 新增：頁首「＋ 新增」，輸入方案名稱。
  • 改名：修改「方案名稱」欄位即可。
  • 複製：下學期沿用同一班時很方便，複製後再改名單或職務。
  • 刪除：會先確認，並自動存一份還原點，誤刪可在「⑤ 資料 → 自動還原點」救回。

手動輸入名單

每行一位，建議格式 座號 姓名，例如 01 王小明；也可以只寫姓名。修改後畫面會出現「名單已修改，尚未套用」，按「套用名單」才會生效，按「放棄修改」可回到原名單。

  • 只改座號（例如 02 李小華 改成 12 李小華）時，程式會依姓名對應，座位與標籤都保留。
  • 若刪掉的學生已經有座位，程式會先列出姓名請您確認。

Excel 匯入

  1. 按「選擇檔案」選 Excel（xlsx、xls、csv）。
  2. 在下拉選單選擇班級分頁，按「匯入此分頁」。
  3. 程式會自動偵測「姓名、座號、學號」等欄位；若已有名單，會先詢問是否取代（同名學生的座位與標籤保留）。

五、② 格局：排數、空位與固定

  • 套用格局：改前後排數（Row）與左右行數（Column）。已排好的學生會留在原位；縮小時超出範圍的學生回到「未安排」，並先列出名單確認。
  • 空位（沒有桌椅）：工具列切到「🧱 編輯格局」，點座位即可在「可用 ↔ 空位」之間切換。空位以斜線底色顯示，隨機分配不會放人。
  • 全部設為可用、解除全部固定：一次重設。

座位代碼：字母代表第幾排（A＝最靠講台的一排），數字代表從左數來第幾個（以學生視角為準）。

六、排座位

隨機分配

按「🎲 隨機分配」會把名單隨機排入可用座位。若已經有安排，會先確認；🔒 固定的學生不會移動。可用座位不夠時會提示還有幾位沒排到。

手動調整（滑鼠、觸控都可以）

想做的事操作方式
兩人交換座位點第一個座位（出現藍框），再點第二個座位。
移到空座位點學生的座位，再點空座位。
把未安排的學生放進座位點下方「未安排的學生」中的姓名，再點座位；座位原本有人時，原來的學生回到未安排。
拖曳座位拖到座位＝交換；學生拖到座位＝放入；座位拖到「未安排的學生」區＝移出座位。
詳細設定雙擊座位，或點選後再點一次同一個座位。
取消選取按 Esc。

座位詳細設定

  • 🔒 固定此座位：特教生、視力或聽力需求、需要坐前排的學生可固定，之後隨機分配都不會移動。固定會跟著學生走（手動交換時一起移動）。
  • 移回未安排、改放其他學生（可搜尋姓名或座號）。
  • 學生標籤：直接選職務或自行輸入。
  • 設為空位／改為可用座位。

復原與清除

  • ↶ 復原（或 Ctrl＋Z，Mac 為 ⌘＋Z）：最多可回復 30 步，包含交換、放入、隨機分配、清除、套用名單／格局、讀取紀錄等。切換班級方案後復原紀錄會清空。
  • 清除安排：只清除座位上的學生，名單、格局、標籤與紀錄都保留；有固定學生時可選擇「保留固定的學生」。

七、③ 標籤：幹部、小老師與備註

標籤存在學生身上，不是存在座位上，所以重新排座位後標籤會跟著學生移動，顯示在座位右上角。

方式 A：匯入幹部小老師程式的 JSON（推薦）

  1. 在「幹部小老師程式」按「下載 JSON」。
  2. 回到本程式「③ 標籤」，按「📥 選擇幹部小老師 JSON」。
  3. 程式依姓名與座號對應，自動標上職務；一人多職會合併（例如 副班長、體育小老師）。
  4. 若本班還沒有名單，會直接用 JSON 中的學生建立名單。

不小心匯入錯檔案，可按提示中的「復原」。

方式 B：個別設定

選擇學生 → 選職務或自行輸入（例如「視力關照」）→「儲存標籤」。下方「已有標籤」清單可點選快速編輯。新學期可用「清除全班標籤」一次清空，不影響名單與座位。

八、④ 紀錄：保存每次的座位

  • 排好後輸入名稱（例如「第一次座位」「段考後」），按「保存」或 Enter。不需要先存方案。
  • 每筆紀錄可「讀取」（換回當時的座位，可復原）、「下載圖檔」、「刪除」。目前讀取中的紀錄會以藍底標示。
  • 紀錄跟著班級方案一起自動儲存與備份。

九、視角、下載與投影

  • 學生視角：講台在上方，適合張貼公告。
  • 教師視角：講台在下方，座位上下左右反轉，符合老師站在講台看學生的方向。
  • ⬇ 下載：輸出學生視角或教師視角 PNG（白底、高解析度），含班級、教室、日期、座位代碼、座號、姓名與標籤。列印時選「符合頁面」。
  • 🖥 投影：座位表全螢幕、字體放大，適合上課時公布座位；按 Esc 離開。

十、⑤ 資料：長期儲存與備份

資料存在哪裡？

位置說明
瀏覽器 IndexedDB（自動）每次修改約 0.3 秒內自動儲存，關閉分頁前也會立即寫出。頁首顯示「💾 已儲存 時間」。只存在這台電腦、這個瀏覽器。
指定資料夾（建議設定）Chrome／Edge 電腦版可選擇資料夾，資料寫成 座位安排資料.json。放在雲端硬碟資料夾，就不怕清除瀏覽器或換電腦。
自動還原點每天第一次儲存留一份（保留 7 天）；清除安排、刪除方案、匯入、還原、載入資料夾前也各留一份（保留 10 份）。可「還原」或「下載」。
JSON 檔（手動）「下載目前班級」或「下載全部資料」，自行保存或交給其他老師。

設定資料夾（第一次）

  1. 用電腦版 Chrome 或 Edge 開啟本程式。
  2. 到「⑤ 資料」按「📁 選擇資料存放資料夾」，選一個資料夾（例如 Google 雲端硬碟電腦版裡的「導師／座位」），允許讀寫。
  3. 頁首出現「📁 已同步到資料夾」即完成。之後每次修改約 2 秒後自動寫入。
  4. 建議在「位置備註」記下資料夾位置（瀏覽器不會顯示完整路徑）。

資料夾內會出現：

  • 座位安排資料.json：目前的正本。
  • 座位安排資料_歷史/：每天第一次寫入前保留前一版，最多 14 份。
  • 座位安排資料_衝突_裝置_時間.json：只有兩台電腦資料衝突時才會出現，是沒被選用的那一份。

每次開啟時

瀏覽器基於安全規定，重新開啟後可能需要再授權一次。頂端會出現黃色提示「點此連接座位資料夾」，按「連接資料夾」並允許即可。授權前畫面顯示的是這台電腦的本機資料。

兩台電腦共用（學校＋家裡）

  1. 兩台電腦都安裝雲端硬碟電腦版，並同步同一個資料夾。
  2. 兩台都在本程式選擇同一個資料夾；第二台若本機也有資料，程式會列出兩邊的班級數、學生數與時間，請選擇要使用哪一份。
  3. 另一台電腦更新後，回到本程式（或每 60 秒）會提示「另一台電腦已更新」，按「載入最新資料」即可。
  4. 兩台都改過時會詢問：載入資料夾的、以本頁覆蓋，或另存衝突檔稍後處理。任何選擇都不會讓資料消失。
  5. 可在「這台電腦的名稱」改成「學校」「家裡」，提示中比較好辨認。
提醒：Safari、Firefox 與手機瀏覽器不支援選擇資料夾，資料只存在該瀏覽器中，請定期按「下載全部資料」備份。以 file:// 直接開啟 HTML 檔時，資料夾功能是否可用依瀏覽器而定，建議使用線上版。

匯入 JSON

「匯入 JSON」可讀取：2.0 的「目前班級」或「全部資料」、舊版（1.x）方案 JSON，以及幹部小老師程式的 JSON（會改為匯入職務標籤）。匯入前會先存還原點；可選擇「加入為新的班級方案」，或（全部資料檔）「取代全部資料」。同名方案會自動加上（2）等編號。

十一、常見問題

關掉網頁後，排好的座位還在嗎？

在。2.0 每次修改都自動儲存，下次用同一個瀏覽器開啟會回到原畫面。若有設定資料夾，換電腦也找得回來。

按錯了怎麼辦？

先按「↶ 復原」。若已切換班級或重新開啟，到「⑤ 資料 → 自動還原點」選擇時間點還原；有設定資料夾時，也可以從 座位安排資料_歷史 取回前幾天的檔案再匯入。

為什麼重新隨機後，標籤還在？

因為標籤存在學生資料上，會跟著學生移動。

為什麼點座位沒有反應或變成空位？

請看工具列目前是「🪑 排座位」還是「🧱 編輯格局」。編輯格局模式中，點座位是切換空位；要排學生請切回排座位。斜線底色的空位不能放學生。

按「套用名單」後少了學生的座位？

名單中刪除或改了姓名的學生會離開座位（程式會先列出並確認）。可按「↶ 復原」回到套用前。

為什麼 Excel 匯入失敗？

請確認檔案為 xlsx、xls 或 csv，表格中有可辨識的姓名欄位，且開啟本程式時可連上網路（需載入 Excel 解析套件）。
