座位選取抽籤程式(canva優化版) 使用說明

本文件協助導師快速完成班級名單匯入、座位抽籤、手動調整、學生職務標籤、歷史紀錄、方案備份與列印輸出。

臺北市麗山高中林獻升老師製作 適用：導師、班級經營、座位安排 文件日期：2026-06-09
線上版網址： https://froglssh.github.io/classroom-seat-lottery/

一、開始使用前

本程式是單頁網頁工具，不需要安裝。老師可直接開啟線上版，或使用本機 HTML 檔。若要使用 Excel 匯入功能，開啟時需能連上網路，讓瀏覽器載入 Excel 解析套件。

  • 建議使用 Chrome、Edge 或 Safari 最新版。
  • 學生名單可手動輸入，也可由 Excel 匯入。
  • 座位方案與歷史紀錄會儲存在同一個瀏覽器的本機資料中。
  • 若要跨電腦使用，請用「下載方案 JSON」備份，再到另一台電腦匯入。

二、匯入或輸入學生名單

方式 A：手動輸入

在「學生名單」欄位中，每行輸入一位學生。建議格式為 座號 姓名，例如：

01 王小明
02 李小華

方式 B：Excel 匯入

  1. 在「Excel 匯入名單」中按「選擇 Excel 檔案」。
  2. 程式會讀取檔案內所有分頁，於「班級分頁」下拉選單中選擇班級。
  3. 按「匯入此班名單」。

程式會自動偵測常見欄位，例如「座號、號碼、編號、學號、姓名、學生、名字」。匯入後會同步保留學生座號與姓名。

三、設定座位格局

  1. 輸入「班級名稱」與「教室名稱」。
  2. 設定橫行數與直列數，例如 5 x 6。
  3. 按「預覽座位設定」。
  4. 在預覽模式中，可點擊座位切換「可用 / 停用」。停用座位會作為空位，不會安排學生。

四、學生標籤：幹部、小老師與備註

學生每學期可能更換職務，因此本程式將職務與備註設計為「學生標籤」，而不是固定在某一個座位上。標籤會跟著學生移動；無論隨機或手動安排，座號右側都會顯示該學生的標籤。

  1. 在「學生標籤設定」中選擇學生。
  2. 從下拉選單選擇幹部或小老師，例如班長、生物小老師。
  3. 也可以手動輸入其他備註。
  4. 按「儲存學生標籤」。

若新學期要重新設定職務，可按「清除此學生標籤」清除單一學生，或按「清除全班學生標籤」一次清除全班職務與備註。這不會刪除學生姓名、座號或座位安排。

五、產生與調整座位

功能用途
生成隨機座位依目前名單與可用座位隨機安排。若人數少於座位數，空位會自然分散。
設定學生座位進入手動分配，可點擊座位選擇學生。
編輯座位可點擊座位重新指定學生，也可拖曳座位交換學生。
清除目前座位清除目前座位上的學生，保留名單、座位格局與學生標籤。

點擊某一個座位時，也可以在視窗中快速調整該學生的標籤。這些標籤會存回學生資料，下次重排仍會保留。

六、學生視角與教師視角

按「教師檢視」可在學生視角與教師視角之間切換。

  • 學生視角：講台 / 黑板在上方。
  • 教師視角：講台 / 黑板在下方，座位上下左右反轉，符合老師站在講台看學生的方向。

七、儲存方案與安排紀錄

儲存方案

在「方案名稱」輸入名稱後按「儲存」。一個方案會包含班級、教室、座位格局、學生名單、學生標籤，以及該方案底下的安排紀錄。

安排紀錄

安排好座位後，可在「安排紀錄」輸入名稱，例如「第一次座位」「段考後座位」，再按「紀錄目前結果」。每個方案可保存多筆安排紀錄；讀取不同方案時，只會看到該方案自己的紀錄。

八、JSON 備份與還原

JSON 檔案代表一個完整方案，而不是單一座位紀錄。

  1. 按「下載方案 JSON」可備份目前方案。
  2. 按「匯入方案 JSON」可將備份方案還原到目前瀏覽器。
  3. 匯入後，方案內的安排紀錄也會一起恢復。
提醒：若換電腦或換瀏覽器使用，原本存在 localStorage 的方案不會自動出現。請先在原電腦下載方案 JSON，再到新電腦匯入。

九、下載與列印座位表

按「下載學生視角 PNG」或「下載教師視角 PNG」可輸出白底黑字的列印友善座位表。圖片中會包含班級、教室、視角、日期、座位代碼、座號、姓名與學生標籤。

  • 學生張貼版通常使用學生視角。
  • 導師講台使用可下載教師視角。
  • 若圖片剛下載後預覽較大，列印時可選擇「符合頁面」或「縮放至一頁」。

十、常見問題

為什麼重新隨機後，幹部或小老師標籤還在？

因為標籤是儲存在學生資料上，不是座位上。這樣每次換座位時，標籤會自動跟著學生移動。

清除全班學生標籤會不會刪掉學生名單？

不會。它只會清除幹部、小老師與備註欄位，學生姓名、座號、座位與方案資料都會保留。

為什麼 Excel 匯入失敗？

請確認檔案格式為 xlsx、xls 或 csv，且表格中至少有可辨識的姓名欄位。若使用線上版，請確認瀏覽器可連網。
