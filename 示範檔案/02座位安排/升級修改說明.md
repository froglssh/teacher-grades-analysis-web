# 教室座位抽籤程式 升級說明（1.x → 2.0）

目標檔案：`座位選取抽籤程式(codex優化版).html`（單一 HTML：Tailwind CDN＋SheetJS CDN＋原生 JavaScript）
原始版備份：`OLD/座位選取抽籤程式(codex優化版)_備份_1.x_20261119.html`（不得修改）

## 一、原程式分析（1.x）

### 1. 資料保存的問題（最嚴重）
| # | 問題 | 影響 |
|---|---|---|
| 1 | 只有按「儲存」才會存；隨機分配、拖曳交換、手動指派**都不會自動存** | 重新整理或關閉分頁，整節課排好的座位全部消失 |
| 2 | 只用 localStorage（`seat_layout_presets_v1`），約 5 MB 上限，清除瀏覽器資料即遺失 | 無長期保存、無法換電腦 |
| 3 | 「安排紀錄」必須先儲存方案才能用，否則跳出提示 | 老師常以為紀錄功能壞掉 |
| 4 | 方案的儲存／讀取／刪除三顆按鈕＋下拉選單，刪除不需確認 | 誤按就刪掉整個班級方案 |
| 5 | 檔尾殘留 Cloudflare 驗證腳本 | 本機開啟時只會載入失敗、主控台出錯 |

### 2. 操作流程的問題
| # | 問題 | 影響 |
|---|---|---|
| 6 | 「預覽座位設定」會**重建整個座位表**，已排好的座位直接清空，沒有確認 | 想改排數就得重排 |
| 7 | 預覽／手動分配／編輯三種模式實際行為幾乎相同（手動與編輯只差視角是否重設），但點座位的效果卻不同（預覽＝切換空位，其他＝開視窗） | 模式意義不清，點錯就把座位變空位 |
| 8 | 隨機分配直接覆蓋，沒有確認也沒有復原；無法「固定」特定學生（如特教生、視力需求坐前排） | 每次重抽都要手動再調 |
| 9 | 名單在每個動作時隱含地重新解析文字框（`updateFromInputs`） | 改了名單卻沒注意，名單外的學生仍留在座位上或被意外清掉 |
| 10 | 只能用 HTML5 拖曳交換；平板／觸控螢幕無法拖曳 | 教室觸控大屏、iPad 無法調座位 |
| 11 | 指派視窗只列「未分配學生」，要換人得先清座位再指派 | 步驟多 |
| 12 | 沒有「復原」 | 任何誤操作都無法回頭 |

### 3. 介面版面的問題
| # | 問題 |
|---|---|
| 13 | 左欄塞了基本設定、Excel、標籤、6 顆彩色動作鈕、2 顆下載、方案、JSON，共 20 多個控制項，視覺權重全相同（彩虹按鈕），找不到主要動作 |
| 14 | 座位表與動作按鈕分在左右兩欄，排座位時視線要來回跳 |
| 15 | 深色玻璃背景＋白色 70% 透明小字（11px），投影到教室時對比不足 |
| 16 | 「未分配學生」只在手動／編輯模式出現，且只是文字，不能點或拖 |
| 17 | 右下角上下捲動按鈕遮住座位，功能與捲軸重複 |
| 18 | 狀態資訊分散（模式在左欄底部、已指派在座位表底部、方案在紀錄區） |
| 19 | 無鍵盤操作、無 `aria` 標記、無法全螢幕投影 |

## 二、2.0 重新設計

### 版面（資訊架構）
```
┌ 頁首：程式名稱｜班級方案下拉＋新增｜💾 已儲存｜📁 已同步到資料夾｜立即儲存 ┐
├ 黃色提示列（資料夾需授權、另一台電腦更新…）                           ┤
├──────────── 左側設定（分頁） ────────────┬──────── 右側工作區 ─────────────┤
│ ① 名單：方案名稱／複製／刪除、班級教室、 │ 工具列：[排座位｜編輯格局]        │
│        名單文字框＋「套用名單」、Excel   │   🎲 隨機分配  ↶ 復原  清除安排   │
│ ② 格局：排數／行數＋「套用格局」（保留   │   [學生視角｜教師視角] 下載 PNG 投影│
│        已排學生）、全部可用、解除固定    │ 統計列：座位／可用／名單／已安排／ │
│ ③ 標籤：幹部 JSON 匯入、個別標籤、清單   │        未安排／固定               │
│ ④ 紀錄：命名保存每次座位、讀取／刪除     │ 操作提示（依模式即時說明）         │
│ ⑤ 資料：資料夾、還原點、JSON 匯出入      │ 講台＋座位表                      │
│                                          │ 未安排學生（可點、可拖）           │
└──────────────────────────────────────────┴───────────────────────────────────┘
```

### 主要改變
1. **只剩兩種模式**：「排座位」（點兩個座位交換、點學生再點座位放入、拖曳、雙擊開詳細設定）與「編輯格局」（點座位切換可用／空位）。
2. **點選交換**：滑鼠與觸控都能用；按 Esc 取消選取。
3. **🔒 固定座位**：在座位詳細設定中固定，隨機分配時不動；交換時鎖定跟著學生走。
4. **↶ 復原**（最多 30 步）：交換、放入、隨機、清除、套用名單／格局、讀取紀錄、切換空位皆可復原。
5. **改排數不再清空**：保留範圍內的座位，超出範圍的學生回到「未安排」，並先確認。
6. **名單需按「套用名單」**才生效；被移出名單的已安排學生會先列出並確認；只改座號時會依姓名自動對應。
7. **班級方案**取代「儲存／讀取／刪除」：所有班級自動儲存，下拉切換；可複製（下學期沿用）、改名、刪除（先留還原點）。
8. **安排紀錄**不必先存方案。
9. **投影**：座位表全螢幕、字體放大。
10. 淺色高對比介面、主要動作單一主色、次要動作灰色、危險動作紅字。

### 儲存層（比照 01 幹部程式 2.0）
- IndexedDB `lssh-seat-arrange`（倉儲 `kv`：`state`、`folderHandle`、`folderKnown`；倉儲 `snapshots`）為主，localStorage `seat-arrange-v2` 為鏡像與後援。
- 每次編輯 0.3 秒內合併寫入；分頁隱藏或關閉時立即寫出；多分頁以 `rev`＋`BroadcastChannel` 提示。
- **舊資料自動搬移**：第一次開啟時讀取舊鍵 `seat_layout_presets_v1` 的所有方案（含安排紀錄、學生標籤），轉成班級方案；舊鍵保留不刪。
- **自動還原點**：每天第一次儲存（保留 7 份）；清除安排、刪除班級、匯入、還原、載入資料夾前（保留 10 份）。隨機重排不留還原點（用「↶ 復原」即可，避免連按把重要還原點擠掉）。
- **資料夾正本**（Chrome／Edge）：`座位安排資料.json`；每天第一次寫入前把前一版複製到 `座位安排資料_歷史/`（保留 14 份）；別台電腦改過時詢問，未選用的一份另存 `座位安排資料_衝突_<裝置>_<時間>.json`。
- JSON 匯出：「目前班級」或「全部資料」；匯入可讀 1.x 方案 JSON、2.0 單一班級、2.0 全部資料，以及幹部小老師程式的 JSON（自動轉到標籤匯入）。

### 測試範圍
- 本機 http 伺服器＋內建瀏覽器實測；資料夾功能以 OPFS 子資料夾替身測試。
- **未實測**：真實資料夾選擇視窗、Google 雲端硬碟同步、`file://` 開啟時的資料夾功能、觸控裝置。
