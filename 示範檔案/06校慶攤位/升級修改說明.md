## 二、儲存架構（比照 00、05 v3.0）

| 層 | 內容 |
|---|---|
| IndexedDB `lssh-stall-planner` | `kv`：`state`、`folderHandle`、`folderKnown`；`snapshots`：還原點 |
| localStorage `lssh.stall.v3` | 鏡像／後援 |
| 資料夾正本（Chrome／Edge） | `園遊會攤位規劃資料.json`；`園遊會攤位規劃資料_歷史/` 每天一份（留 14 份）；兩台電腦衝突時另存 `園遊會攤位規劃資料_衝突_<裝置>_<時間>.json` |

- 0.3 秒合併寫入 IndexedDB；2 秒後寫入資料夾；切換或關閉分頁時立即寫出。
- 回到頁面與每 60 秒檢查資料夾是否被另一台電腦更新。
- 自動還原點：每天 1 份（留 7 天）；套用方案、匯入、還原、開新規劃、清除、載入資料夾前各 1 份（留 10 份）。
- 舊資料搬移：第一次開啟時讀 `lssh.stall.v1.*`（沒有前綴鍵時才讀舊舊版無前綴鍵，與 v2 相同），轉成人員 ID 後寫入 IndexedDB，讀回比對一致才採用；舊鍵原樣保留。v2「下載完整備份」的 JSON 也能直接還原。

## 三、名冊連動

- **獨立版**：「編輯名單 → 班級學生資料」可讀：①同一來源（同網址開啟）的 00 IndexedDB `lssh-student-data`（先用 `indexedDB.databases()` 確認存在，不會建立空資料庫），再退回其 localStorage 鏡像；②已連結資料夾中的 `班級學生資料.json`；③自選該 JSON 檔。只讀座號與姓名。
- **工作站（共享整合版）**：主程式內建 `WS` 模式，名單＝共用名冊在籍學生，以共用學生 ID 記錄；改名自動更新，轉出者以刪除線顯示、不計名額。資料存工作站共用資料庫鍵 `fair-v3`；第一次開啟會自動轉入舊整合版的 `lssh.stall.v1.*` 資料。
- 名單對應規則：同 ID → 同座號＋姓名 → 唯一同名 → 同座號（改名）。
- 已不在名單的人：保留在原組（刪除線）、不計入名額，名單卡片提示「全部移除」。

## 五、測試紀錄（本機 http 伺服器 8797 埠＋內建瀏覽器，獨立網址來源，不影響工作站 8766 的資料）
