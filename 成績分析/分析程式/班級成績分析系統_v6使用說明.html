智慧班級成績分析系統 v6 使用說明
臺北市立麗山高中 林獻升老師 製作

📊 智慧班級成績分析系統 v6

給導師的使用說明：把學校系統匯出的班級成績冊上傳，就能看到班級總覽、各科診斷、預警關懷名單與每位學生的個人報告。本說明依 v6 程式（檔名 班級成績分析系統_v6.html）的實際功能撰寫。

🌟 這個程式做什麼

這是一個單一 HTML 檔的成績分析工具，用瀏覽器打開就能用，不需要安裝、不需要帳號，也不會把成績傳到任何伺服器。它的定位很單純：

  • 只讀學校成績冊，不改成績。程式沒有修改分數、新增科目、設定滿分或及格線的功能；總分、平均、名次一律以成績冊為準（成績冊沒有名次時才由系統依平均補算，並會標示「系統計算」）。
  • 以一個班級為單位。同一屆三年的段考都累積在「目前這一屆」，可以看趨勢、比較進退步。
  • 分析給老師看，報告也可以給學生和家長看。學生版個人報告只含該生自己的成績與全班統計數字，不含其他同學的個別成績。
💡 適合的使用時機：段考成績出來後的導師班會、親師座談前準備個人成績單、學期末追蹤需要關懷的學生、在導師知能研習示範數據輔助班級經營。
🚀 三步驟上手
  1. ① 上傳學校成績冊：用 Chrome 或 Edge 打開 班級成績分析系統_v6.html，把學校系統匯出的班級成績冊（.xls 或 .xlsx）拖到虛線框，或點一下框框選檔。一次可以選多份，系統會依考試時間（學年、學期、第幾次）自動排序。
  2. ② 確認驗證結果：每一份檔案都會先跳出「驗證視窗」，列出人數、科目、選修人數、名單異動等。確認沒問題再按「確認，載入資料」。（看不懂的提示請參考下一節「驗證視窗怎麼看」。）
  3. ③ 看分析：建議從「🏫 班級分析 → 班級總覽」開始看（第一次使用時預設就在這頁；之後程式會記住您上次看的分頁）。上方的「目前分析的考試」可以切換要看哪一次段考。
✨ 先試玩：還沒有成績冊時，可按「✨ 載入示範班級（3 次段考，合成資料）」。示範資料是程式隨機產生的虛構學生，適合研習時操作練習。若目前已經有資料，載入示範班級前系統會先把目前這一屆封存，之後可以切換回來。

已經有資料時，上傳區會收成一列，只顯示屆別、已載入幾份考試、「＋ 上傳新成績」按鈕、「顯示學生姓名」開關與「⚙️ 設定」。要再上傳時按「＋ 上傳新成績」展開拖放區即可。

📄 成績冊格式說明

程式是針對學校系統匯出的「班級成績一覽表」設計，不需要另外整理。它會自動找出以下內容（以下表格為虛構示意）：

座號姓名國語文
4/4		英語文
4/4		數學
4/4		…總分平均班級名次

  • 標題列：從「○○○學年度 上／下學期 班級 考試別」自動取得學年、學期、班級與考試名稱，考試會自動命名為例如「115上 第一次期中考」，並依時間排序。
  • 座號、姓名：成績冊沒有姓名欄也可以分析，只是跨考試辨識同一位學生、轉入轉出判斷都只能用座號。
  • 科目欄：表頭含科目名稱即可；表頭下的「4/4」會讀成學分。同一個科目名稱出現兩次（例如同名選修分成 1 學分、2 學分兩門）時，系統會自動加上「（1學分）」「（2學分）」區分。
  • 「#」：成績冊以 # 標示不及格，程式會讀出分數並標成紅字。
  • 輔助欄：總分、平均、不及格數、班級名次、班級進退、類組名次、類組進退、類組百分名次。沒有班級名次或進退時，系統依平均自動計算並註明「系統依平均分數自動計算」。
  • 底部統計列：平均、高標、及格比率、標準差、班級人數等會一併讀入，在「五標統計」以黃底列並列，也用來核對程式計算是否正確。
⚠️ 注意：請直接上傳學校匯出的原檔，不要先在 Excel 裡合併儲存格、刪表頭或加註解列，以免欄位對不上。
🔍 驗證視窗怎麼看

每份檔案載入前都會跳出驗證視窗。最上面一行是摘要，例如「解析完成：29 位學生 / 7 科 ｜ 0 錯誤 / 1 警告」。紅框「錯誤」必須處理（按鈕會無法按）；黃框「警告」請看一下是否合理；藍框是參考資訊。

提示代表什麼怎麼處理
人數核對
「成績冊記載班級人數 N 人，但讀入 M 位學生」		成績冊底部的班級人數和程式讀到的學生列數不同。打開原檔核對是否有學生列沒有座號或格式特殊；確認無誤再載入。
各科修習人數（藍框）
「○○：選修，6 人修習」		修習人數不到全班一半的科目視為選修，統計只算有修的學生。正常現象。人數少於 10 人的科目，分析頁會提醒「人數太少，僅供參考」。若不想讓選修科影響全班分析，可在「⚙️ 設定」排除。
「○○：未有成績 N 人」大部分人有成績，少數人空白（缺考、免修等）。確認是否符合實際狀況。
未讀入欄位
「下列表頭欄位未被辨識，未讀入分析」		有表頭欄位程式不認得，該欄不會進入分析。若那欄是科目成績，請把原檔與提示內容告訴製作老師；若是備註欄可忽略。
「程式計算平均 … 與成績冊平均 … 相差」程式算出的該科平均與成績冊底部平均不同，可能欄位對錯。先不要載入，核對原檔欄位。
「未能完整解析考試時間」標題列讀不到學年／學期／考試別。可以載入，但會依上傳順序排列；載入後可在考試標籤用 ◀ ▶ 調整順序、✏️ 改名。
「已載入過同名考試」同一份成績冊可能上傳了兩次。若是重複上傳請按取消；確定要載入，系統會自動命名為「名稱(2)」。
「未偵測到班級名次」成績冊沒有名次欄。載入後由系統依平均計算名次與進退，並標示為系統計算。
👥 名單核對：同一屆，有異動和時間上相鄰的考試比對姓名：
・轉出：較早名單有、較晚名單沒有的姓名
・轉入：新出現的姓名
・座號異動：姓名相同、座號不同（視為同一人）		確認後系統會記錄異動：轉出生保留歷史成績；轉入生的多次比較、趨勢、預警與成長分析只從轉入後開始算。個人報告標題會標示「○○起轉入」等字樣。
🎓 換屆警告
「偵測到換屆（或不同班級）」		座號與姓名都相同的人不到一半，可能是新的一屆或上傳到別班的成績冊。如果真的是新一屆，按「🎓 建立新一屆」：系統先把目前這一屆整個封存（可隨時切換回來），再開始新的一屆。若是傳錯檔，按「取消上傳」。
「成績冊沒有姓名，無法判斷…」沒有姓名欄，無法判斷換屆或轉學。請自行確認是同一班的成績。
💡 驗證視窗是給導師核對用的，會直接顯示名單異動的姓名。投影示範時請留意。
🧭 全域考試切換與四組導覽

目前分析的考試

分頁列右上方（手機在分頁列下方）有「目前分析的考試」選單與 ◀ ▶ 按鈕。所有分頁共用這一個選擇：切換後，成績一覽、五標、全班分析、名次、預警、個人分析、班級總覽與最上方的「班級體質儀表板」都會一起換成這份考試；「與上次比較」一律是和時間上的前一份考試比。上傳區的考試標籤也可以點一下考試名稱來切換；◀ ▶ 用來調整考試先後順序，✏️ 改名，× 移除這份考試。

四組導覽

第一層第二層子分頁
📋 成績資料成績一覽、五標統計
🏫 班級分析班級總覽、全班分析、名次分析、多次比較、預警關懷、進階計量診斷
🧑‍🎓 個人分析個人分析、個人多次比較
💾 輸出與儲存報告與匯出、資料與儲存

程式會記住您上次看的分頁，重新開啟時直接回到那裡；第一次使用（或有資料時）預設在「班級總覽」。手機或平板上，分頁列可以左右滑動。

小「?」名詞說明：畫面上專有名詞旁的小「?」，滑鼠移上去或點一下就會出現一句白話解釋（例如五標、PR、標準差、偏態、VAM）。列印時不會出現。
📊 各分頁怎麼讀

🏫 班級總覽（建議先看）

老師版一頁摘要：一句話總評（班平均、與上次比較、及格人次比率、及格率最低科目、預警人數與建議）、關鍵數字、各科一列精簡表（人數、平均、學校高標、及格率、與上次差、需關注標記）、平均進步／退步最多的前五位（需有前一份考試；依姓名比對同一人，本次轉入的同學不列入）、預警分級人數，以及本次轉入、轉出、座號異動摘要。按「🖨️ 列印班級總覽」可印成 A4 一頁或另存 PDF。

📋 成績一覽

全班成績表，可搜尋座號（顯示姓名時也可搜尋姓名）、點表頭排序、切換熱力圖、點一列跳到該生個人分析。「🧩 顯示欄位」可加開班級 PR、與班平均差、與上次平均差。紅底為不及格；在目前顯示的這份考試中被排除的科目，表頭會標「分析排除」，但成績照常顯示。

📏 五標統計

各科頂標、前標、均標、後標、底標（第 88／75／50／25／12 百分位）及平均、標準差等。黃底列是成績冊底部的原始數值；成績冊的「高標」是前 50% 學生的平均，和五標定義不同，數字不必相同。

📈 全班分析

各科平均、及格率、成績分布、雷達圖、五標折線、箱型圖、程度分群、科目相關矩陣、各科教學診斷表、臨界學生名單。每個區塊上方的綠框是依實際數值自動產生的白話結論（「這代表什麼」＋「老師可以怎麼做」）；修習人數少於 10 人的科目會加註「人數太少，僅供參考」。

📊 名次分析

班級名次、進退、類組名次與百分名次的表格與圖表（成績冊有提供才顯示）。

🔄 多次比較

需兩份以上考試。「全班比較」看各科平均、及格率、標準差的歷次變化；「個人比較」（在「🧑‍🎓 個人分析 → 個人多次比較」）看單一學生的歷次成績與趨勢。

🚨 預警關懷

依不及格科數、均分、名次退步、均分驟降、單科明顯低於個人均分、臨界不及格、連續下滑等規則計分，分成高度關注、中度關注、持續留意。這是老師版頁面，用語較直接；名單可下載 Excel。判定規則寫在頁面下方，標準可自行調整（見下一節）。

🔬 進階計量診斷

  • 信度衰減校正關聯：扣除測量誤差後，估計兩科底層能力的關聯；只計算每科都有成績的學生。
  • 增值評量（VAM）：用前兩次考試預測「目前分析的考試」，找出明顯超出或低於預期的學生（包括分數及格但明顯退步的「隱性危機」）。目前分析的考試之前要至少還有兩份考試。
  • 成長軌跡：用這一屆全部考試（3 次以上）算每位學生的起點與每次平均進退幾分，列出持續進步、持續下滑、起伏大的學生。

每個區塊上方都有白話結論；考試次數或人數不足時，會直接寫「次數／人數太少，僅供參考」或「暫不提供結論」，不會硬下結論。

🧑‍🎓 個人分析

選擇學生後顯示各科成績、班平均、差距、Z／T 分數、五標位置、評等、偏科指數、三張圖與「讀書策略與下次目標」。可用鍵盤 ← → 切換學生；「🔄 看這位學生的多次比較」直接跳到個人多次比較。上方的「學生版報告選項」見後面說明。

⚙️ 排除科目與預警標準

排除科目（上傳區的「⚙️ 設定」）

每份考試各自設定：面板標題會寫明是哪一次考試（例如「分析時排除科目 ─ 115上 第一次期中考」），只列出「目前分析的考試」的科目，勾選只影響這一次；要設定其他次考試，先在上方切換目前分析的考試，面板內容會跟著換。按「套用到這一屆所有考試」可把這一次的勾選依科目名稱套到其他每份考試的同名科目（其他考試沒有對應的科目不變，會先詢問確認）。新上傳的考試，同名科目會沿用時間上前一份考試的勾選。

勾選的科目（例如國防、體育等藝能科，或人數很少的選修）在該次考試不列入讀書策略、教學診斷、相關與進階計量、預警單科規則、雷達與科目比較圖、儀表板及格人次比率與班級總覽精簡表。多次比較、趨勢與「與上次差」等跨考試分析中，每份考試各照自己的設定：某科在某次被排除，那一次就不提供該科的資料（表格標示「排除」或「—」、圖表該點留空），不會被當成 0 分或退步；科目清單列出至少在一份考試中未被排除的科目。成績一覽表仍完整顯示；總分、平均、名次一律以成績冊為準，不會因排除而改變。設定會自動儲存，並隨考試一起保存在封存屆別、JSON 備份與資料夾正本中；舊版的整屆共用設定在載入時會自動轉成各考試的設定。

「⚙️ 設定」裡也有「🗑️ 清除目前這一屆的資料」：只清除目前這一屆，封存的屆別不受影響；清除前會自動建立還原點。

調整預警標準（預警關懷頁的「⚙️ 調整預警標準」）

可改各項門檻，例如不及格科數、均分門檻、名次退步名數、均分驟降分數、臨界分數範圍等，每一項都顯示預設值；改完立即重算並儲存，只影響預警名單與儀表板的預警人數。按「↺ 恢復預設」回到原本規則。

🧑‍🎓 學生版報告選項與發放注意事項

個人分析頁上方、以及「報告與匯出」頁的「全班學生個別報告」區，都有兩個同步的選項：

選項說明
顯示班級名次（預設開）關閉時，個人分析頁與個人報告（列印、單一學生 PDF、全班個人報告）都不出現班級名次、類組名次、名次進退、預估名次與 PR，只保留自己的分數、與班平均／五標的位置、進退步分數。適合不想強調排名的班級或家長說明會。
附家長閱讀說明（預設開）報告最後附一段白話說明：五標是什麼、紅字（成績冊上的 #）代表不及格、怎麼看進退步，以及建議和孩子一起討論的三個問題。
報告標題顯示姓名（報告與匯出頁）決定個人報告的標題與內文是否出現姓名，和畫面上的「顯示學生姓名」開關無關。成績冊沒有姓名時自動停用。

「讀書策略與下次目標」等自動文字使用中性、鼓勵式的說法（例如「與班平均還有一段距離」「最近往下、可再加油的科目」），分類方式與數值不變。轉入、轉出、座號異動會在報告標題旁標示。

📮 發給學生／家長前請確認：
  • 每份報告只含該生自己的成績與班級統計（班平均、五標等），不含其他同學的個別成績。
  • 確認選對學生、座號範圍與考試；姓名是否顯示依「報告標題顯示姓名」選項。
  • 自動建議只是依分數算出的參考，請搭配平日觀察與任課老師意見；名次與 PR 只是班內相對位置。
  • PDF 檔含學生成績，傳送時請一人一檔或紙本分發，不要整份全班檔寄給家長或貼到群組。

🗄️ 資料儲存、屆別、還原點與 JSON 備份

自動儲存（不用按存檔）

載入、改名、排除科目、調整預警標準、切換考試等變更都會自動存在這台電腦這個瀏覽器裡（IndexedDB，另有一份 localStorage 鏡像）。標題列右上的徽章會顯示「已儲存 時:分」。下次用同一台電腦、同一個瀏覽器打開同一個檔案，資料會自動載入。內容沒有變動時不會重複寫入。

⚠️ 注意：資料跟著「瀏覽器」走，不是跟著 HTML 檔走。換電腦、換瀏覽器、使用無痕視窗或清除瀏覽器資料後，就看不到原本的資料——請用下面的「指定資料夾」或「JSON 備份」保存。同一台電腦同時開兩個分頁修改時，後改的分頁會提示「另一個分頁已修改資料，請重新載入」，避免互相覆蓋。

屆別（💾 輸出與儲存 → 🗄️ 資料與儲存 → 屆別資料）

同一屆三年的考試都累積在「目前這一屆」，屆別名稱會自動依入學學年度與班級命名（例如「115學年度入學・107班」），可重新命名。上傳時偵測到換屆並按「建立新一屆」，舊的一屆會被封存；封存的屆別可以「切換到這一屆」查看（目前這一屆會自動封存保留），也可以刪除。

自動還原點

清除資料、建立新一屆、刪除屆別、匯入 JSON、以資料夾內容取代本機之前，系統會自動留一份還原點（保留最近 10 份），可在「資料存放位置與狀態 → 自動還原點」還原或下載。

手動備份（JSON）

「⬇️ 匯出全部 .json」＝所有屆別（目前＋封存）與設定；「只匯出目前這一屆」＝只有目前這一屆。「⬆️ 匯入 .json」可在另一台電腦載入（匯入前會自動建立還原點，也能讀舊版備份檔）。沒有載入任何考試時，這些功能在上傳區下方的「🗄️ 屆別資料與資料存放位置」也找得到。

📁 指定資料夾長期保存（兩台電腦共用）

只有電腦版 Chrome 或 Edge支援。指定一個資料夾後，資料夾內的 班級成績分析資料.json 就是正本，瀏覽器裡的資料是本機快取。建議選雲端硬碟的同步資料夾（例如 Google 雲端硬碟電腦版的資料夾），兩台電腦選同一個資料夾就會讀寫同一份資料。

設定步驟

  1. 到「💾 輸出與儲存 → 🗄️ 資料與儲存 → 資料存放位置與狀態」。
  2. （建議）在「這台電腦的名稱」填「辦公室」「家裡」等，方便辨識是哪台電腦寫入的。
  3. 按「📁 選擇資料存放資料夾」，選好資料夾並允許瀏覽器讀寫。
  4. 系統會比對資料夾與本機資料：資料夾是空的就寫入；兩邊內容不同時會詢問要採用哪一份（被取代的一方會先留備份）。
  5. 瀏覽器不會告訴程式完整路徑，請在「位置備註」記下您選的是哪個資料夾（備註會存進正本，兩台電腦都看得到）。

平常使用

  • 每次本機儲存後約 2 秒，自動寫入資料夾；標題列會出現「📁 已同步・資料夾名稱」。
  • 每天第一次寫入前，會在 班級成績分析資料_歷史 子資料夾留一份歷史備份，保留最近 14 份。
  • 重新開啟程式時，瀏覽器通常會要求再授權一次：請按頁面上方提示列的「點此連接資料夾」。授權並比對完成前，程式不會寫入資料夾。
  • 可按「立即寫入」「從資料夾重新載入」「更換資料夾」「解除連結」。
兩台電腦共用的注意事項：
  • 不要兩台電腦同時編輯。換電腦前，等雲端硬碟同步完成（雲端硬碟圖示顯示已同步）再在另一台開啟。
  • 程式每分鐘、以及切回視窗時會檢查資料夾；發現另一台電腦更新過，會提示「載入最新資料」。
  • 寫入前若發現正本被另一台電腦改過且內容不同，會「暫停寫入資料夾」並請您按「處理衝突」選擇要保留哪一份；被取代的資料夾內容會另存衝突檔，本機內容會留還原點。
  • 資料夾內的檔案含學生姓名與成績，雲端硬碟資料夾不要分享給他人。
🔒 隱私與離線使用
  • 成績不會上傳：解析、統計、圖表、PDF 都在您的瀏覽器裡完成。
  • 可離線使用：Excel 解析、圖表、PDF 產生所需的元件都已內嵌在 HTML 檔中，沒有網路也能使用（沒網路時字型會改用電腦內建字型，不影響功能）。
  • 「顯示學生姓名」開關：預設關閉，畫面與輸出只顯示座號，適合投影或研習示範；需要時再打開。
  • 含姓名的檔案：JSON 備份、資料夾正本、還原點下載檔都含學生姓名與成績，請妥善保管。
  • 公用電腦：用完請到「⚙️ 設定」清除目前這一屆的資料，或在「屆別資料」刪除封存的屆別；也可清除瀏覽器的網站資料。
❓ 常見問題

Q1. 打開檔案後之前的資料不見了？

資料存在瀏覽器裡：請確認是同一台電腦、同一個瀏覽器、不是無痕視窗，並且是同一個網址（同一個檔案位置）開啟。若有連結資料夾，按提示列「點此連接資料夾」即可讀回；也可匯入 JSON 備份或從自動還原點還原。

Q2. 考試順序不對？

標題列沒有學年／學期／考試別時會依上傳順序排列。請在上傳區的考試標籤用 ◀ ▶ 調整（順序＝趨勢分析的時間順序），用 ✏️ 改名。

Q3. 為什麼某科顯示「人數太少，僅供參考」？

修習人數少於 10 人（通常是選修）。少數人的平均、相關係數很容易被一兩位同學影響。可以在「⚙️ 設定」把這科排除在分析之外。

Q4. 進階計量診斷說「考試次數太少」？

增值評量需要目前分析的考試之前至少還有兩份考試；成長軌跡需要這一屆累積 3 份以上考試。

Q5. 系統計算的名次和學校公告不同？

只有成績冊沒有名次欄時，系統才會依平均分數自動計算（有標示）。請以學校公告為準。

Q6. 學期中有學生轉入或轉出怎麼辦？

正常上傳即可。驗證視窗會列出轉入、轉出與座號異動；確認後，轉入生的比較與預警只從轉入後開始算，轉出生保留歷史成績。

Q7. 下載 PDF 失敗？

請改用「🖨️ 列印全班個人報告」，在列印視窗選「另存為 PDF」。人數多時可分座號範圍分批產生。

Q8. 出現「另一個分頁已修改資料」？

同一個檔案在兩個分頁開啟並修改了。請按「重新載入」，以最新的資料繼續；只保留一個分頁使用。

Q9. Safari 或手機能用嗎？

分析、列印、JSON 備份都可以使用；「指定資料夾」只有電腦版 Chrome、Edge 支援。
